## Salvare e aprire

**File → Salva** (<kbd>Ctrl</kbd> <kbd>S</kbd>) scrive un file `.lapin`, e **File → Apri…** (<kbd>Ctrl</kbd> <kbd>O</kbd>) ne apre uno.

- **App desktop.** Il file viene salvato dove scegli.
- **Browser, Chrome ed Edge.** Lapin salva ogni volta nello stesso file.
- **Browser, Safari e Firefox.** Ogni salvataggio scarica il file.

Un file `.lapin` contiene l’intero progetto: il modello, le viste, le tavole, i materiali con le loro immagini, e le versioni.

## Recuperare il lavoro non salvato

Lapin conserva il tuo lavoro non salvato man mano che procedi. Se l’app o il computer si fermano prima che tu salvi, alla volta successiva la schermata iniziale ti propone di recuperarlo.

## Versioni

Una versione è il progetto com’è nel momento in cui lo salvi come versione: prima di una riunione con il cliente, o alla fine di una fase di progettazione. Apri **File → Salva versione…** oppure **Gestisci → Versioni**.

![Versioni: salva il progetto com’è ora](shots/versions.webp)

Le versioni vivono all’interno del file del progetto, e le parti che una versione condivide con il progetto sono conservate una sola volta. Dall’elenco puoi:

- rinominare una versione;
- aggiornarla allo stato attuale, con una revisione;
- confrontarla con il progetto, elemento per elemento;
- ripristinarla, come un solo passo che puoi annullare;
- esportarla o aprirla separatamente;
- eliminarla.

## Annulla

<kbd>Ctrl</kbd> <kbd>Z</kbd> annulla, e <kbd>Ctrl</kbd> <kbd>Y</kbd> o <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> ripete. I pulsanti **Annulla** e **Ripeti** nella barra superiore, a destra di **Comandi…**, fanno lo stesso in ogni modalità dell’interfaccia, e il loro suggerimento dice che cosa annullano; così anche **File → Annulla** e **File → Ripeti**, e la tavolozza dei comandi (<kbd>Ctrl</kbd> <kbd>K</kbd>, digita “annulla”).
