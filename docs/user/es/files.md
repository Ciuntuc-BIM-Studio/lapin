## Guardar y abrir

**Archivo → Guardar** (<kbd>Ctrl</kbd> <kbd>S</kbd>) escribe un archivo `.lapin`, y **Archivo → Abrir…** (<kbd>Ctrl</kbd> <kbd>O</kbd>) abre uno.

- **Aplicación de escritorio.** El archivo se guarda donde usted elija.
- **Navegador, Chrome y Edge.** Lapin guarda cada vez en el mismo archivo.
- **Navegador, Safari y Firefox.** Cada guardado descarga el archivo.

Un archivo `.lapin` contiene todo el proyecto: el modelo, las vistas, las láminas, los materiales con sus propias imágenes y las versiones.

## Recuperar el trabajo no guardado

Lapin conserva su trabajo no guardado sobre la marcha. Si la aplicación o el ordenador se detienen antes de que guarde, la pantalla de inicio le ofrece recuperarlo la próxima vez.

## Versiones

Una versión es el proyecto tal como está en el momento en que lo guarda como tal: antes de una reunión con el cliente o al final de una fase de diseño. Abra **Archivo → Guardar versión…** o **Gestionar → Versiones**.

![Versiones: guardar el proyecto tal como está ahora](shots/versions.webp)

Las versiones viven dentro del archivo del proyecto, y las partes que una versión comparte con el proyecto se guardan una sola vez. Desde la lista puede:

- cambiar el nombre de una versión;
- actualizarla al estado actual, con una revisión;
- compararla con el proyecto, elemento por elemento;
- restaurarla, como un solo paso que puede deshacer;
- exportarla o abrirla por separado;
- eliminarla.

## Deshacer

<kbd>Ctrl</kbd> <kbd>Z</kbd> deshace, y <kbd>Ctrl</kbd> <kbd>Y</kbd> o <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> rehace. Los botones **Deshacer** y **Rehacer** de la barra superior, a la derecha de **Comandos…**, hacen lo mismo en todos los modos de la interfaz, y su información sobre herramientas indica qué deshacen; también **Archivo → Deshacer** y **Archivo → Rehacer**, y la paleta de comandos (<kbd>Ctrl</kbd> <kbd>K</kbd>, escriba "deshacer").
