# Lapin-Benutzerhandbuch

Lapin ist ein BIM-Modellierer für Architekten und Ingenieure. Sie zeichnen Wände, Decken, Dächer, Türen und Fenster im Grundriss. Lapin baut daraus das 3D-Modell und zeichnet die Schnitte, Ansichten und Pläne, die Sie drucken. Jedes Element ist ein echtes IFC-Element, sodass das Modell unverändert in andere BIM-Werkzeuge übernommen werden kann.

Lapin läuft an zwei Orten:

- **Auf Ihrem Computer.** Die Desktop-Anwendung für Windows, macOS und Linux ist am schnellsten. Sie aktualisiert sich selbst.
- **Im Browser.** [lapin.ciuntucbimstudio.ro](https://lapin.ciuntucbimstudio.ro/web/) führt dieselbe Anwendung aus, ohne dass Sie etwas installieren müssen. Sie ist etwas langsamer.

## Kostenlos, Open Source und Helpware

Lapin ist kostenlos und Open Source, unter der MIT-Lizenz; der Code liegt auf [GitHub](https://github.com/Ciuntuc-BIM-Studio/lapin). Lapin ist außerdem **Helpware**: Wenn Lapin Ihnen in irgendeiner Weise hilft, ermutigen wir Sie, ohne Sie dazu zu verpflichten, jemandem zu helfen, der Hilfe braucht, auf jede Weise, die Ihnen möglich ist: mit Ihrer Zeit, Ihren Fähigkeiten, einer helfenden Hand für jemanden in Ihrer Nähe, einer Gabe an Menschen oder an eine Sache, der Sie vertrauen. Lapin verlangt nichts für sich selbst und nimmt keine Spenden an.

## Wenn Sie nicht weiterkommen

Klicken Sie auf **Ask Me**, das Kaninchen oben rechts in der Anwendung, oder drücken Sie <kbd>F1</kbd>, und stellen Sie Ihre Frage in Ihren eigenen Worten. Wenn es keine Antwort hat, sendet es Ihre Frage an uns. Siehe [Hilfe und Feedback](help.md).
