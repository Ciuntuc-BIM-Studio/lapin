## Speichern und Öffnen

**Datei → Speichern** (<kbd>Strg</kbd> <kbd>S</kbd>) schreibt eine `.lapin`-Datei, und **Datei → Öffnen…** (<kbd>Strg</kbd> <kbd>O</kbd>) öffnet eine.

- **Desktop-App.** Die Datei wird dort gespeichert, wo Sie es wählen.
- **Browser, Chrome und Edge.** Lapin speichert jedes Mal in dieselbe Datei.
- **Browser, Safari und Firefox.** Jedes Speichern lädt die Datei herunter.

Eine `.lapin`-Datei enthält das ganze Projekt: das Modell, die Ansichten, die Pläne, die Materialien mit ihren eigenen Bildern und die Versionen.

## Ungespeicherte Arbeit wiederherstellen

Lapin bewahrt Ihre ungespeicherte Arbeit laufend auf. Wenn die App oder der Computer stoppt, bevor Sie speichern, bietet der Startbildschirm beim nächsten Mal an, sie wiederherzustellen.

## Versionen

Eine Version ist das Projekt so, wie es in dem Moment ist, in dem Sie es als Version speichern: vor einem Kundentermin oder am Ende einer Planungsphase. Öffnen Sie **Datei → Version speichern…** oder **Verwalten → Versionen**.

![Versionen: das Projekt so speichern, wie es jetzt ist](shots/versions.webp)

Versionen liegen in der Projektdatei, und die Teile, die eine Version mit dem Projekt teilt, werden nur einmal aufbewahrt. In der Liste können Sie:

- eine Version umbenennen;
- sie auf den aktuellen Stand bringen, mit einer Revision;
- sie mit dem Projekt vergleichen, Element für Element;
- sie wiederherstellen, als ein Schritt, den Sie rückgängig machen können;
- sie exportieren oder separat öffnen;
- sie löschen.

## Rückgängig

<kbd>Strg</kbd> <kbd>Z</kbd> macht rückgängig, und <kbd>Strg</kbd> <kbd>Y</kbd> oder <kbd>Strg</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> stellt wieder her. Die Schaltflächen **Rückgängig** und **Wiederholen** in der oberen Leiste, rechts von **Befehle…**, tun dasselbe in jedem Oberflächenmodus, und ihr Tooltip sagt, was sie rückgängig machen; ebenso **Datei → Rückgängig** und **Datei → Wiederholen** sowie die Befehlspalette (<kbd>Strg</kbd> <kbd>K</kbd>, „undo“ eingeben).
