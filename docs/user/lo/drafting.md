## ແຖວຄຳສັ່ງ

ພິມຕົວອັກສອນຂອງເຄື່ອງມືຢູ່ບ່ອນໃດກໍໄດ້ໃນໜ້າຕ່າງ, ຈາກນັ້ນກົດ <kbd>Enter</kbd>. ຕົວຢ່າງ, ພິມ <kbd>WA</kbd> ສຳລັບຝາ, <kbd>CO</kbd> ເພື່ອສຳເນົາ, <kbd>M</kbd> ເພື່ອຍ້າຍ, ຫຼື <kbd>L</kbd> ສຳລັບເສັ້ນ. ແຖວຄຳສັ່ງຢູ່ທາງລຸ່ມຈະສະແດງສິ່ງທີ່ເຄື່ອງມືຕ້ອງການຕໍ່ໄປ. ທ່ານສາມາດຄລິກໃສ່ຈຸດໃດໜຶ່ງ ຫຼື ພິມຄວາມຍາວ, ມຸມ ຫຼື ຄ່າພິກັດ.

ຄ່າພິກັດທີ່ພິມແມ່ນຢູ່ໃນຫົວໜ່ວຍຂອງໂຄງການ, ຄືກັນກັບຄວາມຍາວທີ່ຢູ່ຂ້າງເຄີເຊີ: ໃນໂຄງການທີ່ເປັນມິນລິແມັດ, `@4000,4000` ຫຼັງຈາກມຸມທຳອິດຂອງຮູບສີ່ແຈສາກຈະເຮັດໃຫ້ມັນມີຂະໜາດ 4 ມ x 4 ມ, ແລະ `4000<90` ແມ່ນ 4 ມ ຊື່ຂຶ້ນເທິງ.

![ກຳລັງສຳເນົາຝາ: ຫຼັງຈາກຈຸດຖານ, ແຖວຄຳສັ່ງ ແລະ ການປ້ອນຂໍ້ມູນແບບສົດໆ ຈະສະແດງຄວາມຍາວ ແລະ ມຸມໄປຫາເມົາສ໌](shots/command-line.webp)

ທຸກໆເຄື່ອງມືຈະສະແດງຕົວອັກສອນຂອງມັນໃນຄຳແນະນຳເຄື່ອງມື (tooltip); ທ່ານສາມາດປ່ຽນພວກມັນໄດ້ໃນ **View → Keyboard shortcuts…** (ເບິ່ງ [ສ່ວນຕິດຕໍ່ຜູ້ໃຊ້ ແລະ ປຸ່ມລັດ](interface.md)). ເຫຼົ່ານີ້ແມ່ນເຄື່ອງມືທີ່ຖືກນຳໃຊ້ຫຼາຍທີ່ສຸດ:

| ແບບຈຳລອງ | | ແຕ້ມແບບ | |
|---|---|---|---|
| ຝາ | <kbd>WA</kbd> | ເສັ້ນ | <kbd>L</kbd> |
| ປະຕູ, ປ່ອງຢ້ຽມ | <kbd>DR</kbd>, <kbd>WN</kbd> | ເສັ້ນຕໍ່ເນື່ອງ (Polyline) | <kbd>PL</kbd> |
| ພື້ນ | <kbd>SB</kbd> | ສີ່ແຈສາກ, ວົງມົນ, ເສັ້ນໂຄ້ງ | <kbd>REC</kbd>, <kbd>C</kbd>, <kbd>A</kbd> |
| ຫຼັງຄາ | <kbd>RF</kbd> | ຍ້າຍ, ສຳເນົາ | <kbd>M</kbd>, <kbd>CO</kbd> |
| ຂັ້ນໄດ, ຫ້ອງ | <kbd>ST</kbd>, <kbd>RM</kbd> | ໝຸນ, ສະທ້ອນ, ປັບຂະໜາດ | <kbd>RO</kbd>, <kbd>MI</kbd>, <kbd>SC</kbd> |
| ເສົາ, ຂານ | <kbd>CL</kbd>, <kbd>BM</kbd> | ອັອບເຊັດ, ຕັດຂອບ, ຕໍ່ເສັ້ນ | <kbd>O</kbd>, <kbd>TR</kbd>, <kbd>EX</kbd> |
| ໜ້າຕັດ | <kbd>SE</kbd> | ລົບມຸມມົນ, ຕັດມຸມຫຼ່ຽມ | <kbd>F</kbd>, <kbd>CHA</kbd> |
| ວັດແທກ | <kbd>ME</kbd> | ລວດລາຍແຮດຊ໌, ຂໍ້ຄວາມ | <kbd>H</kbd>, <kbd>T</kbd> |
| ສະແດງທັງໝົດ | <kbd>ZE</kbd> | ລຶບ | <kbd>E</kbd> |

## ການວັດແທກ

**ວັດແທກ** (<kbd>ME</kbd>, ເຄື່ອງມືດ່ວນອັນທີສອງ, ຫຼື **MEASURE** ຫຼື **DIST** ໃນແຖວຄຳສັ່ງ) ວັດແທກໂດຍບໍ່ຕ້ອງແຕ້ມຫຍັງເລີຍ: ຄລິກໃສ່ຈຸດຕ່າງໆ ໃນແປນ, ໜ້າຕັດ ຫຼື ຮູບດ້ານ, ພ້ອມທັງສະແນັບໄປນຳ, ແລ້ວກົດ <kbd>Enter</kbd>. ໃນຂະນະທີ່ທ່ານຄລິກ, ການປ້ອນຂໍ້ມູນແບບສົດໆ ຈະສະແດງຄວາມຍາວ ແລະ ມຸມຂອງແຕ່ລະຊ່ວງ; ເມື່ອສິ້ນສຸດ ການແຈ້ງເຕືອນຈະບອກຄວາມຍາວລວມ, ແຕ່ລະຊ່ວງ (ສຳລັບຊ່ວງດຽວ, ຄ່າ Δx, Δy ແລະ ມຸມຂອງມັນ) ແລະ ເນື້ອທີ່ທີ່ພວກມັນອ້ອມຮອບ ຕັ້ງແຕ່ສາມຈຸດຂຶ້ນໄປ.

## ການສະແນັບ ແລະ ຕົວຊ່ວຍ

Lapin ຈະສະແນັບໃສ່ຈຸດປາຍ, ຈຸດເຄິ່ງກາງ ແລະ ຈຸດຕັດກັນ ຂອງສິ່ງທີ່ຖືກແຕ້ມ, ແລະ ໃສ່ຕາໜ່າງກຣິດ. <kbd>F3</kbd> ເປີດ ຫຼື ປິດການສະແນັບ, <kbd>F8</kbd> ໂໝດ ortho ແລະ <kbd>F10</kbd> ການຕິດຕາມມຸມ (polar tracking). ສະຖານະຂອງພວກມັນຈະສະແດງຢູ່ມຸມຂວາລຸ່ມຂອງມຸມມອງ.

## ການເລືອກ

ຄລິກໃສ່ອົງປະກອບໃດໜຶ່ງເພື່ອເລືອກມັນ; ກົດ <kbd>Shift</kbd>-ຄລິກ ເພື່ອເພີ່ມເຂົ້າໃນການເລືອກ. ເພື່ອເລືອກຫຼາຍອັນພ້ອມກັນ, ໃຫ້ລາກດ້ວຍປຸ່ມຊ້າຍໃນບ່ອນທີ່ບໍ່ມີຫຍັງຖືກເລືອກ. ຖ້າລາກໄປທາງຂວາ, ກ່ອງຈະເປັນສີຟ້າ ແລະ ເລືອກເອົາສິ່ງທີ່ຢູ່ພາຍໃນມັນທັງໝົດ (window); ຖ້າລາກໄປທາງຊ້າຍ, ກ່ອງຈະເປັນສີຂຽວເສັ້ນຂາດ ແລະ ເລືອກເອົາທຸກສິ່ງທີ່ມັນສຳຜັດ (crossing), ຄືກັນກັບໃນ AutoCAD. ກົດ <kbd>Space</kbd> ໃນຂະນະທີ່ທ່ານລາກ ແລ້ວກ່ອງຈະກາຍເປັນເຊືອກບ້ວງ (lasso) ທີ່ແລ່ນຕາມເມົາສ໌, ໂດຍຮັກສາໂໝດເດີມຂອງກ່ອງໄວ້; ກົດ <kbd>Space</kbd> ອີກເທື່ອໜຶ່ງເພື່ອຍ້ອນກັບໄປເປັນກ່ອງ. ໃນແຖວຄຳສັ່ງ, ໃນຂະນະທີ່ຄຳສັ່ງຮ້ອງຂໍໃຫ້ທ່ານເລືອກວັດຖຸ, ໃຫ້ພິມ **WP** ຫຼື **CP** ແລ້ວຄລິກຕາມມຸມຕ່າງໆ ຂອງຮູບຫຼາຍແຈ, ຈາກນັ້ນກົດ <kbd>Enter</kbd>: ນັ້ນຄືຮູບຫຼາຍແຈແບບ window ຫຼື ຮູບຫຼາຍແຈແບບ crossing.

![ເຊືອກບ້ວງໃນແປນ: ລາກກ່ອງໄປທາງຂວາ, ຈາກນັ້ນກົດ Space, ແລະ ວົງອ້ອມຝາສອງອັນທີ່ມັນກວມເອົາ](shots/select-lasso.webp)

## ການສຳເນົາ ແລະ ການຍ້າຍ

ເພື່ອສຳເນົາ, ໃຫ້ເລືອກອົງປະກອບແລ້ວພິມ <kbd>CO</kbd>. ຄລິກຈຸດຖານ, ຈາກນັ້ນຄລິກຈຸດທີສອງ. Lapin ຈະສຳເນົາຕໍ່ເນື່ອງໄປເລື້ອຍໆ ຈົນກວ່າທ່ານຈະກົດ <kbd>Enter</kbd> ຫຼື <kbd>Esc</kbd>. **ຍ້າຍ** (<kbd>M</kbd>) ເຮັດວຽກໃນແບບດຽວກັນ.

ໃນຂະນະທີ່ທ່ານຍ້າຍ ຫຼື ສຳເນົາ, ເຄື່ອງໝາຍຈະຄ້າງຢູ່ຈຸດຖານ ແລະ ມີເສັ້ນຂາດແລ່ນຈາກຈຸດນັ້ນໄປຫາເມົາສ໌, ພ້ອມທັງມີເສັ້ນເຄົ້າຈາງໆ ຂອງສິ່ງທີ່ທ່ານຍ້າຍປະໄວ້ຢູ່ບ່ອນເກົ່າ ຈົນກວ່າທ່ານຈະຄລິກ ຫຼື ກົດ <kbd>Esc</kbd>. ເສັ້ນ ແລະ ເຄື່ອງໝາຍຈະປ່ຽນສີຕາມການສະແນັບ: ສີຂຽວເທິງຈຸດທີ່ສະແນັບຕິດ, ສີຟ້າເມື່ອ ortho ຫຼື polar tracking ກຳນົດທິດທາງໄວ້, ສີເນັ້ນໃສ່ເສັ້ນຕິດຕາມ, ສີເທົາເມື່ອເປັນອິດສະຫຼະ. ຢູ່ຂ້າງເມົາສ໌, Lapin ຈະສະແດງໄລຍະທາງທີ່ທ່ານຍ້າຍໄປ: Δx, Δy, ໄລຍະຫ່າງ ແລະ ມຸມ, ໃນຫົວໜ່ວຍຂອງໂຄງການ. ທ່ານສາມາດພິມໄລຍະຫ່າງ ແລະ ມຸມຢູ່ບ່ອນນັ້ນໄດ້ເລີຍ, ຄືກັນກັບເວລາທີ່ທ່ານແຕ້ມ. ໃນສ່ວນຕິດຕໍ່ຜູ້ໃຊ້ແບບກະທັດຮັດ (Compact), ຄ່າເຫຼົ່ານີ້ຈະຢູ່ໃນແຖວສະຖານະ. ການລາກຈຸດກຣິບຈະສະແດງສິ່ງດຽວກັນ, ແລະ ການລາກອົງປະກອບທີ່ຖືກເລືອກເອງກໍຄືກັນ, ຈາກຈຸດທີ່ທ່ານກົດ; ກົດ <kbd>Esc</kbd> ກ່ອນທີ່ທ່ານຈະປ່ອຍ ແລ້ວອົງປະກອບຈະຍັງຄົງຢູ່ບ່ອນເກົ່າ.

![ການຍ້າຍຝາ: ເຄື່ອງໝາຍເທິງຈຸດຖານ, ເສັ້ນຂາດໄປຫາເມົາສ໌, ເງົາຮ່າງຂອງຝາຢູ່ບ່ອນເກົ່າ ແລະ ໄລຍະເລື່ອນຢູ່ເມົາສ໌](shots/move-trace.webp)

ທ່ານຍັງສາມາດລາກແທນໄດ້. ລາກເຄື່ອງໝາຍກາກບາດຢູ່ເຄິ່ງກາງຂອງອົງປະກອບທີ່ຖືກເລືອກເພື່ອຍ້າຍມັນ. ກົດ <kbd>Ctrl</kbd> ຄ້າງໄວ້ (<kbd>⌘</kbd> ເທິງ Mac) ໃນຂະນະທີ່ລາກເພື່ອປະສຳເນົາໄວ້.

ປະຕູ, ປ່ອງຢ້ຽມ ຫຼື ຊ່ອງເປີດຝາ ຈະຍ້າຍ ແລະ ສຳເນົາໄປຕາມຝາຂອງມັນ: ສະເພາະສ່ວນຂອງການຍ້າຍທີ່ໄປຕາມຝາເທົ່ານັ້ນທີ່ຈະຖືກຄິດໄລ່, ດັ່ງນັ້ນການພິມ `500` ຫຼັງຈາກຈຸດຖານຈະເລື່ອນມັນໄປ 500 ຕາມແນວຝາ; ຖ້າຍ້າຍເຂົ້າໄປໃນຝາອື່ນ, ມັນກໍຈະເຂົ້າໄປຢູ່ໃນຝານັ້ນ. ຖ້າເລືອກຝາຂອງມັນພ້ອມ, ມັນກໍຈະໄປພ້ອມກັບຝາ.

ແກນຕາໜ່າງສາມາດຍ້າຍ, ສຳເນົາ, ໝຸນ ແລະ ສະທ້ອນໄດ້ດ້ວຍຕົວມັນເອງ, ຫຼື ໄປພ້ອມກັບອົງປະກອບອື່ນໆ. ການສຳເນົາຈະເປັນແກນໃໝ່ຂອງຕາໜ່າງດຽວກັນ, ໂດຍຕັ້ງຊື່ຕາມແກນສຸດທ້າຍທີ່ແລ່ນໄປໃນທິດທາງດຽວກັນ: ຖ້າມີແກນ 1, 2 ແລະ 3, ການສຳເນົາແກນໃດໜຶ່ງໃນນັ້ນຈະໄດ້ເປັນ 4.

## ການແຕ້ມແບບ

ແຖບ **Draft** ໃຊ້ແຕ້ມເສັ້ນ, ເສັ້ນຕໍ່ເນື່ອງ, ສີ່ແຈສາກ, ວົງມົນ ແລະ ເສັ້ນໂຄ້ງ. ມັນດັດແກ້ພວກມັນດ້ວຍການອັອບເຊັດ, ຕັດຂອບ, ຕໍ່ເສັ້ນ, ລົບມຸມມົນ, ຕັດມຸມຫຼ່ຽມ ແລະ ເຊື່ອມຕໍ່, ໃສ່ລວດລາຍແຮດຊ໌ໃນພື້ນທີ່, ແລະ ຈັດລະບຽບພວກມັນເທິງ **Layers** (ຊັ້ນຂໍ້ມູນ). **Import DXF** ຈະນຳຮູບແຕ້ມ CAD ເຂົ້າມາເປັນເສັ້ນທີ່ທ່ານສາມາດສະແນັບໃສ່ ແລະ ດັດແກ້ໄດ້.

![ແຖບ Draft](shots/ribbon-draft.webp)

**Offset** (<kbd>O</kbd>) ສຳເນົາເສັ້ນ, ເສັ້ນຕໍ່ເນື່ອງ, ສີ່ແຈສາກ, ວົງມົນ ຫຼື ເສັ້ນໂຄ້ງ ຕາມໄລຍະຫ່າງ. ພິມໄລຍະຫ່າງໃນຫົວໜ່ວຍຂອງໂຄງການ (ໃນໂຄງການທີ່ເປັນມິນລິແມັດ `500` ແມ່ນເຄິ່ງແມັດ; `2m` ຫຼື `1'6"` ລະບຸຫົວໜ່ວຍຂອງພວກມັນເອງ), ຄລິກໃສ່ຮູບຮ່າງ, ຈາກນັ້ນຄລິກໃສ່ເບື້ອງທີ່ມັນຈະໄປ; ມັນຈະຖາມຫາຮູບຮ່າງຕໍ່ໄປຈົນກວ່າທ່ານຈະກົດ <kbd>Enter</kbd> ຫຼື <kbd>Esc</kbd>. ພິມ **T** (Through) ແທນ ແລ້ວແຕ່ລະສຳເນົາຈະຜ່ານຈຸດທີ່ທ່ານຄລິກ. ມຸມຂອງເສັ້ນຕໍ່ເນື່ອງຈະຍັງຄົມຊັດ (mitred) ຄືກັນກັບໃນ CAD. ການອັອບເຊັດສາມາດໃຊ້ໄດ້ໃນແປນ, ໜ້າຕັດ, ຮູບດ້ານ, ເທິງລະນາບອ້າງອີງ ແລະ ໃນມຸມມອງ 3D.

ທຸກໆຄວາມຍາວທີ່ແຖວຄຳສັ່ງຖາມຫາແມ່ນຢູ່ໃນຫົວໜ່ວຍຂອງໂຄງການ, ແລະ ຂໍ້ຄວາມແຈ້ງເຕືອນຈະບອກວ່າແມ່ນຫົວໜ່ວຍໃດ: `Depth (mm)`, `Height (ft-in)`. ສ່ວນມຸມ, ຕົວຄູນ ແລະ ຈຳນວນ ແມ່ນຕົວເລກທຳມະດາ: `90` ຫຼັງຈາກ **Rotate** ແມ່ນ 90° ບໍ່ວ່າຈະເປັນຫົວໜ່ວຍໃດກໍຕາມ.

### ການແຕ້ມແບບໃນມຸມມອງ 3D

**Line**, **Polyline**, **Rectangle**, **Circle**, **Arc** ແລະ ຄຳສັ່ງດັດແກ້ການແຕ້ມແບບ ສາມາດເຮັດວຽກໃນມຸມມອງ 3D ໄດ້ຄືກັນ, ໂດຍມີແຖວຄຳສັ່ງຢູ່ທາງລຸ່ມ. ໃນຂະນະທີ່ຄຳສັ່ງກຳລັງເຮັດວຽກ, ປ້າຍຂໍ້ຄວາມ (chip) ຢູ່ທາງເທິງຈະບອກບ່ອນທີ່ທ່ານແຕ້ມ: ເທິງລະດັບຊັ້ນທີ່ເປີດໃຊ້ງານຢູ່, ຫຼື ເທິງລະນາບອ້າງອີງທີ່ທ່ານເລືອກ. **Pick a face** ໃນປ້າຍຂໍ້ຄວາມ, ແລ້ວຄລິກໃສ່ໜ້າໃດໜຶ່ງຂອງແບບຈຳລອງ, ຈະສ້າງລະນາບອ້າງອີງເທິງໜ້ານັ້ນ ແລະ ແຕ້ມໃສ່ເທິງມັນ. ຈຸດຕ່າງໆ ຈະສະແນັບຄືກັນກັບໃນແປນ: ໃສ່ເສັ້ນຕັດຂອງແປນ (ມຸມ ແລະ ໜ້າຂອງຝາ) ແລະ ໃສ່ສິ່ງທີ່ຖືກແຕ້ມແບບເທິງລະນາບດຽວກັນ, ພ້ອມດ້ວຍ ortho ແລະ ເສັ້ນຊີ້ບອກແນວທາງການຕິດຕາມ. ສິ່ງທີ່ທ່ານແຕ້ມແມ່ນອົງປະກອບແຕ້ມແບບອັນດຽວກັນກັບທີ່ແຕ້ມເທິງແປນ, ແລະ ຈະສະແດງຢູ່ທີ່ນັ້ນຄືກັນ.

![ການແຕ້ມແບບໃນມຸມມອງ 3D: ປ້າຍຂໍ້ຄວາມບອກລະນາບ, ເສັ້ນແລ່ນຕາມເມົາສ໌ເທິງລະດັບຂອງຊັ້ນ](shots/draft-3d.webp)

### ແບບຮ່າງໃນມຸມມອງ 3D

ສິ່ງທີ່ທ່ານແຕ້ມແບບເທິງແປນ (ເສັ້ນ, ເສັ້ນຕໍ່ເນື່ອງ, ສີ່ແຈສາກ, ວົງມົນ, ເສັ້ນໂຄ້ງ) ຈະຕັ້ງຢູ່ໃນມຸມມອງ 3D ເຊັ່ນກັນ, ເປັນເສັ້ນທີ່ລະດັບຂອງຊັ້ນນັ້ນ (ຕົວລະດັບເອງ, ບໍ່ແມ່ນຄວາມສູງໜ້າຕັດຂອງແປນ); ສິ່ງທີ່ທ່ານແຕ້ມເທິງລະນາບອ້າງອີງ, ໜ້າຕັດ ຫຼື ຮູບດ້ານ ຈະຕັ້ງຢູ່ເທິງລະນາບນັ້ນ. ຄລິກໃສ່ອັນໃດໜຶ່ງໃນ 3D ເພື່ອເລືອກມັນ, ຈາກນັ້ນຍ້າຍ, ສຳເນົາ, ອັອບເຊັດ ຫຼື ລຶບມັນ. **View → Drafts in 3D**, ເຊິ່ງມີຢູ່ໃນ **View → View settings** ຂອງມຸມມອງ 3D ເຊັ່ນກັນ, ໃຊ້ເພື່ອສະແດງ ຫຼື ເຊື່ອງພວກມັນທັງໝົດ; ມັນຈະເປີດຢູ່ສະເໝີ ນອກຈາກວ່າທ່ານຈະປິດມັນ. ເສັ້ນບອກຂະໜາດ, ຂໍ້ຄວາມ, ແທັກ, ລວດລາຍແຮດຊ໌ ແລະ ເສັ້ນຊ່ວຍສ້າງ (role draft) ຈະຍັງຄົງຢູ່ໃນມຸມມອງຂອງພວກມັນເອງ, ແລະ ໄຟລ໌ DXF ທີ່ນຳເຂົ້າມາໃສ່ໃນແປນ ຈະຍັງຄົງເປັນຮູບແຕ້ມ 2D, ເວັ້ນເສຍແຕ່ເສັ້ນຂອງມັນທີ່ມີຄ່າຄວາມສູງ.

### ລຳດັບການແຕ້ມ

ບ່ອນທີ່ອົງປະກອບທີ່ແຕ້ມເກີດການທັບຊ້ອນກັນ, ອັນທີ່ແຕ້ມທີຫຼັງຈະຢູ່ທາງເທິງ. ເພື່ອປ່ຽນແປງມັນ, ໃຫ້ເລືອກພວກມັນ (ເສັ້ນ, ເສັ້ນຕໍ່ເນື່ອງ, ສີ່ແຈສາກ, ວົງມົນ, ເສັ້ນໂຄ້ງ, ລວດລາຍແຮດຊ໌ ແລະ ການຖອກສີ, ຂໍ້ຄວາມ, ເສັ້ນບອກຂະໜາດ, ແທັກ, ຮູບຮ່າງຂອງ DXF), ຄລິກຂວາ ແລ້ວເລືອກ **Bring to front**, **Bring forward**, **Send backward** ຫຼື **Send to back**; ເມນູ **Draft → Order** ແລະ **Annotate → Order** ກໍມີຄຳສັ່ງດຽວກັນ, ພ້ອມດ້ວຍປຸ່ມລັດ <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd>, <kbd>Ctrl</kbd>+<kbd>]</kbd>, <kbd>Ctrl</kbd>+<kbd>[</kbd> ແລະ <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>[</kbd> (⌘ ເທິງ Mac). Forward ແລະ backward ຈະຂ້າມຜ່ານອົງປະກອບຖັດໄປທີ່ການເລືອກນັ້ນທັບຊ້ອນຢູ່. ສ່ວນການແຕ້ມແບບຈະແຕ້ມທັບເທິງຮູບແຕ້ມຂອງຕົວແບບຈຳລອງເອງ; **Send behind the model** ຈະເອົາມັນໄປໄວ້ກ້ອງເສັ້ນຕັດ ແລະ ເສັ້ນທີ່ເບິ່ງເຫັນຂອງຝາ (ລວດລາຍແຮດຊ໌ຢູ່ກ້ອງຝາ), ແລະ ການຄລິກໃສ່ບ່ອນນັ້ນຈະເລືອກເອົາຝາ; **Bring to front** ຫຼື **Send to back** ຈະເອົາມັນກັບມາຢູ່ເທິງແບບຈຳລອງອີກຄັ້ງ. ໃນແຖວຄຳສັ່ງ, **DRAWORDER** (**DRO**) ຈະຖາມຫາວັດຖຸ, ຈາກນັ້ນເລືອກ **Above objects** ຫຼື **Under objects** (ຄລິກອົງປະກອບທີ່ພວກມັນຈະໄປຢູ່ເທິງ ຫຼື ກ້ອງ, ແລ້ວກົດ <kbd>Enter</kbd>), **Front**, **Back** ຫຼື ຢູ່ທາງຫຼັງ **Model**. ລຳດັບນີ້ເປັນຂອງມຸມມອງນັ້ນໆ, ສາມາດຍົກເລີກໄດ້ເທື່ອລະຂັ້ນຕອນ, ແລະ ໜ້າແຜ່ນງານ, PDF ແລະ DXF ຈະພິມອອກມາຕາມທີ່ທ່ານເຫັນ; ສິ່ງທີ່ທ່ານແຕ້ມຫຼັງຈາກນັ້ນຈະຂຶ້ນມາຢູ່ທາງເທິງ.

## ການໃສ່ຄຳອະທິບາຍປະກອບ

ແຖບ **Annotate** ປະກອບດ້ວຍເສັ້ນບອກຂະໜາດ, ຂໍ້ຄວາມ, ແກນຕາໜ່າງ, ລະດັບ ແລະ ແທັກ. ເສັ້ນບອກຂະໜາດຈະອ່ານຄ່າຈາກແບບຈຳລອງ, ດັ່ງນັ້ນມັນຈະອັບເດດເມື່ອຝາມີການຍ້າຍ. ຮູບລັກສະນະຂອງຂໍ້ຄວາມ, ເສັ້ນບອກຂະໜາດ, ແກນ ແລະ ແທັກ ຖືກຕັ້ງຄ່າໃນ **Manage → Drafting standards**.

ເສັ້ນບອກຂະໜາດແບບປັບແນວ (aligned) ຫຼື ແບບເສັ້ນກົງ (linear) ຈະຕໍ່ເນື່ອງກັນເປັນສາຍ: ຫຼັງຈາກສອງຈຸດທຳອິດ ແລະ ເສັ້ນຂອງມັນ, ແຕ່ລະຄລິກຈະເພີ່ມຈຸດຖັດໄປເທິງເສັ້ນດຽວກັນ, ແລະ **Enter** (ຫຼື **Esc**) ຈະເຮັດໃຫ້ທັງສາຍກາຍເປັນເສັ້ນບອກຂະໜາດອັນດຽວ (**U** ຈະຍົກເລີກຈຸດສຸດທ້າຍ; ພິມ **S** ກ່ອນ ສຳລັບເສັ້ນບອກຂະໜາດດ່ຽວ). ສາຍເສັ້ນບອກຂະໜາດເຮັດວຽກຄືກັນກັບເສັ້ນຕໍ່ເນື່ອງ: ການຄລິກຄັ້ງດຽວຈະເລືອກມັນທັງໝົດ, ແລະ ຍ້າຍ, ສຳເນົາ ແລະ ລຶບໄປພ້ອມກັນເປັນອັນດຽວ. ສາຍທີ່ວັດແທກຝາ, ຂອບ ຫຼື ແກນຕາໜ່າງ ຈະຍຶດຕິດຢູ່ກັບສິ່ງເຫຼົ່ານັ້ນ: ເມື່ອຖືກລາກ ຫຼື ຍ້າຍດ້ວຍຕົວມັນເອງ, ຈະມີພຽງເສັ້ນບອກຂະໜາດເທົ່ານັ້ນທີ່ເລື່ອນ, ຕັ້ງສາກກັບສາຍ, ດັ່ງນັ້ນການພາດຂອງເມົາສ໌ຈະບໍ່ເຮັດໃຫ້ມັນວັດແທກພື້ນທີ່ຫວ່າງເປົ່າ; ຖ້າຍ້າຍໄປພ້ອມກັບສິ່ງທີ່ມັນວັດແທກ, ມັນກໍຈະໄປນຳກັນ. ຈຸດກຣິບຂອງມັນຈະຢູ່ແຕ່ລະຈຸດທີ່ວັດແທກ (ລາກເພື່ອຍ້າຍມັນ, Ctrl/⌘-ຄລິກ ເພື່ອເອົາມັນອອກ), ຢູ່ເຄິ່ງກາງຂອງແຕ່ລະຊ່ວງ (ລາກເພື່ອເພີ່ມຈຸດ, Ctrl/⌘-ຄລິກ ເພື່ອເພີ່ມຈຸດເຄິ່ງທາງ) ແລະ ຢູ່ປາຍຂອງເສັ້ນບອກຂະໜາດ (ລາກເພື່ອຍ້າຍເສັ້ນ). ເພື່ອໃສ່ຈຸດເພີ່ມເຕີມເຂົ້າໃນສາຍ, ຄືກັນກັບໃນ ArchiCAD, ໃຫ້ເລືອກມັນແລ້ວຄລິກ **Annotate → Add points** (ຫຼື ພິມ **DIMADD**, ຫຼື **Add points** ໃນຄຸນສົມບັດຂອງມັນ): ແຕ່ລະຈຸດທີ່ທ່ານຄລິກຈະເຂົ້າໄປຢູ່ໃນສາຍບ່ອນທີ່ມັນຕົກຕາມແນວເສັ້ນ, ລະຫວ່າງຈຸດອ້ອມຂ້າງ ຫຼື ເລີຍຈຸດປາຍອອກໄປເປັນຈຸດປາຍໃໝ່, ແລະ ຍຶດຕິດກັບຝາ, ຂອບ ຫຼື ແກນທີ່ມັນລົງໄປ; **Enter** ຫຼື **Esc** ເພື່ອສິ້ນສຸດ. ເພື່ອເອົາຈຸດອອກ, Ctrl/⌘-ຄລິກ ໃສ່ຈຸດກຣິບຂອງພວກມັນ, ຫຼື ຄລິກ **Annotate → Remove points** (**DIMDEL**, ຫຼື **Remove points** ໃນຄຸນສົມບັດຂອງມັນ) ແລ້ວຄລິກໃກ້ໆ ແຕ່ລະຈຸດ; ຊ່ວງທັງສອງເບື້ອງຈະຮວມເຂົ້າກັນເປັນຊ່ວງດຽວ. ຄ່າຂອງແຕ່ລະຊ່ວງກໍມີຈຸດກຣິບຄືກັນ: ລາກມັນເພື່ອຍ້າຍຄ່າອອກຈາກບ່ອນເກົ່າໃນບ່ອນທີ່ຊ່ວງສັ້ນ ແລະ ຄ່າຈະທັບຊ້ອນກັນ; ເມື່ອມັນຢູ່ຫ່າງອອກຈາກຊ່ວງຂອງມັນ, ຈະມີເສັ້ນຊີ້ບາງໆ ໂຍງກັບຄືນມາ. Ctrl/⌘-ຄລິກ ໃສ່ຈຸດກຣິບ, ຫຼື **Texts back on the line** ໃນຄຸນສົມບັດ, ເພື່ອເອົາມັນກັບຄືນມາບ່ອນເກົ່າ. ຄ່າທີ່ຖືກຍ້າຍຈະຍັງຄົງຢູ່ກັບຊ່ວງຂອງມັນເມື່ອຈຸດຕ່າງໆ ມີການຍ້າຍ, ແລະ ໝຸນໄປພ້ອມກັບສາຍ. ຄລິກສອງເທື່ອໃສ່ຊ່ວງໃດໜຶ່ງເພື່ອພິມຄ່າຂອງມັນ: ອົງປະກອບທີ່ມັນວັດແທກຈະຍ້າຍ, ແລະ ທຸກຢ່າງທີ່ຢູ່ຖັດຈາກມັນໃນສາຍກໍຈະຍ້າຍໄປຄືກັນ. ສ່ວນຄຸນສົມບັດຈະສະແດງຄ່າ ແລະ ຂໍ້ຄວາມຂອງແຕ່ລະຊ່ວງ, ແຍກສາຍອອກເປັນເສັ້ນບອກຂະໜາດດ່ຽວ, ແລະ ເຊື່ອມຕໍ່ເສັ້ນບອກຂະໜາດດ່ຽວທີ່ຕໍ່ເນື່ອງກັນຢູ່ເທິງເສັ້ນດຽວກັນ.

ຄຳອະທິບາຍປະກອບເທິງແປນ (ເສັ້ນບອກຂະໜາດ, ຂໍ້ຄວາມ, ເສັ້ນແຕ້ມ, ແທັກ) ສາມາດຍ້າຍໄປໃສ່ແປນອື່ນຕາມຕຳແໜ່ງເດີມໄດ້, ເນື່ອງຈາກແປນຕ່າງໆ ໃຊ້ຄ່າພິກັດຮ່ວມກັນ: ເລືອກພວກມັນ ແລະ ເລືອກແປນໃນຄຸນສົມບັດຂອງພວກມັນ, ກ້ອງຫົວຂໍ້ **View** ເພື່ອຍ້າຍພວກມັນ ຫຼື **Copy to** ເພື່ອສຳເນົາພວກມັນ. ວິທີນີ້ຍັງນຳເອົາເສັ້ນບອກຂະໜາດທີ່ສ້າງຂຶ້ນເທິງຜັງບໍລິເວນ (site plan) ມາຍັງແປນພື້ນຂອງຊັ້ນນັ້ນໄດ້ອີກດ້ວຍ. ຈາກນັ້ນຈຸດຕ່າງໆ ຂອງເສັ້ນບອກຂະໜາດຈະຍຶດຕິດກັບສິ່ງທີ່ແປນໃໝ່ຕັດຜ່ານຢູ່ບ່ອນນັ້ນ: ຝາ, ຂອບ, ແກນ.

**ຄວາມສູງຂອງຊ່ອງເປີດ.** ຊ່ວງຂອງສາຍເສັ້ນບອກຂະໜາດທີ່ແລ່ນຈາກວົງກົບເບື້ອງໜຶ່ງຂອງປະຕູ, ປ່ອງຢ້ຽມ ຫຼື ຊ່ອງເປີດໂລ່ງ ໄປຫາອີກເບື້ອງໜຶ່ງ ຈະຂຽນຄວາມກວ້າງໄວ້ເທິງເສັ້ນ ແລະ ຂຽນຄວາມສູງຂອງຊ່ອງເປີດໄວ້ກ້ອງເສັ້ນ, ຄືກັນກັບແບບແຕ້ມຂອງໂຣມານີ ແລະ ເອີຣົບ. ຄ່ານີ້ຈະຖືກອ່ານຈາກແບບຈຳລອງທຸກໆ ຄັ້ງ, ດັ່ງນັ້ນມັນຈະປ່ຽນຕາມຊ່ອງເປີດເມື່ອມີການປ່ຽນຂະໜາດ, ຍ້າຍ ຫຼື ປ່ຽນເປັນປະເພດອື່ນ; ຊ່ວງທີ່ທ່ານພິມຂໍ້ຄວາມທັບລົງໄປຈະບໍ່ຂຽນຄ່ານີ້. **Manage → Drafting standards → Dimensions → Opening height** ໃຊ້ຕັ້ງຄ່າສຳລັບແຕ່ລະຮູບແບບເສັ້ນບອກຂະໜາດ: ປິດ, `150`, `h=150`, `h=150` ພ້ອມຂອບລຸ່ມ (sill) `p=90` ຢູ່ກ້ອງມັນ, ຫຼື `150/90`, ໃນຫົວໜ່ວຍຂອງຮູບແບບນັ້ນ. ມັນໃຊ້ໄດ້ໃນແປນ, ໜ້າຕັດ ແລະ ຮູບດ້ານ, ແລະ ໜ້າແຜ່ນງານ, PDF ແລະ DXF ຈະພິມມັນອອກມາ. ໂຄງການໃໝ່ຈະເປີດຄຸນສົມບັດນີ້ໄວ້ (ສະເພາະຄວາມສູງຢ່າງດຽວ); ໂຄງການທີ່ສ້າງມາກ່ອນຈະຮັກສາເສັ້ນບອກຂະໜາດໄວ້ຄືເກົ່າ ຈົນກວ່າທ່ານຈະເປີດມັນຢູ່ບ່ອນນັ້ນ.

### ແທັກ

**Annotate → Tag** (<kbd>TG</kbd>) ຈະໃສ່ກ່ອງລົງໃນມຸມມອງພ້ອມກັບຂໍ້ມູນທີ່ອົງປະກອບບອກກ່ຽວກັບຕົວມັນເອງ, ແລະ ເສັ້ນຊີ້ໄປຫາມັນ. ໃນຂະນະທີ່ເຄື່ອງມືເປີດຢູ່, ແຖບກ້ອງມຸມມອງຈະເລືອກສິ່ງທີ່ແທັກຈະສະແດງ: ເຄື່ອງໝາຍ (mark), ຊື່, ຊັ້ນ (class) ຫຼື ປະເພດ, **Fire rating** (ອັດຕາການທົນໄຟ), **Acoustic rating** (ອັດຕາການກັນສຽງ), **Thermal transmittance** (ການຖ່າຍເທຄວາມຮ້ອນ), ຫຼື **Another parameter…** ຕາມຊື່ຂອງມັນ; ຫຼື ປະເພດແທັກຂອງມາດຕະຖານການແຕ້ມແບບ; ແລະ **LEADER** ໃຊ້ເປີດ ຫຼື ປິດເສັ້ນຊີ້. ຄລິກໃສ່ອົງປະກອບ, ຈາກນັ້ນຄລິກບ່ອນທີ່ແທັກຈະໄປຢູ່ (ພິມ **E** ກ່ອນ ເພື່ອຫັກງໍເສັ້ນຊີ້ເປັນຂໍ້ສອກ). **Annotate → Tag a parameter** ຈະຖາມຫາຊື່ພາຣາມິເຕີ ແລະ ເລີ່ມຕົ້ນເຄື່ອງມືດ້ວຍຄ່ານັ້ນ.

![ແຖບເຄື່ອງມືແທັກກ້ອງມຸມມອງ](shots/tag-options.webp)

ແທັກສາມາດອ່ານພາຣາມິເຕີໃດກໍໄດ້: ຂອງຕົວອົງປະກອບເອງ, ຂອງປະເພດຂອງມັນ (ແລ້ວທຸກໆ ອົງປະກອບຂອງປະເພດນັ້ນກໍຈະສະແດງມັນ), ຄຸນສົມບັດມາດຕະຖານ ເຊັ່ນ `Pset_WallCommon.FireRating`, ຫຼື ຄ່າທີ່ຕິດມາກັບອົງປະກອບທີ່ນຳເຂົ້າ. ຊື່ຈະຖືກຄົ້ນຫາໂດຍບໍ່ສົນໃຈຍະຫວ່າງ, ດັ່ງນັ້ນ **Fire rating** ແລະ `FireRating` ຈຶ່ງຄືກັນ. ເພື່ອປ້ອນຂໍ້ມູນໃສ່, ໃຫ້ໃຊ້ **Parameters** ໃນຄຸນສົມບັດຂອງອົງປະກອບ ຫຼື ຂອງປະເພດຂອງມັນ: ພິມຊື່ (ມີຕົວເລືອກ Fire rating, Sound rating, Moisture resistance ແລະ Thermal resistance ໃຫ້), ຫຼື ເລືອກ **Add a standard property…** ສຳລັບຄຸນສົມບັດ IFC ຂອງຊັ້ນນັ້ນ. ແທັກຈະສະແດງຕາມທັນທີທີ່ມີຄ່າ, ແລະ ຄວາມຍາວຈະຖືກຂຽນໃນຫົວໜ່ວຍຂອງໂຄງການ.

ແທັກທີ່ຖືກເລືອກຈະມີຈຸດກຣິບ. ລາກກ່ອງເພື່ອຍ້າຍແທັກ: ເສັ້ນຊີ້ຈະຍັງຄົງຊີ້ໄປບ່ອນເດີມ. ແທັກຈະໄປພ້ອມກັບອົງປະກອບຂອງມັນ: ເມື່ອອົງປະກອບຖືກຍ້າຍ, ໝຸນ, ສະທ້ອນ ຫຼື ປ່ຽນຮູບຮ່າງດ້ວຍຈຸດກຣິບ, ແທັກຂອງມັນກໍຈະໄປຕາມ, ໂດຍຮັກສາຕຳແໜ່ງຢູ່ຂ້າງມັນໄວ້, ແລະ ເສັ້ນຊີ້ຈະຍັງຄົງຢູ່ເທິງມັນ; ແທັກທີ່ທ່ານເຄີຍຍ້າຍຈະຮັກສາໄລຍະຫ່າງທີ່ທ່ານຕັ້ງໄວ້. ລາກເຄິ່ງກາງຂອງເສັ້ນຊີ້ເພື່ອງໍມັນເປັນຂໍ້ສອກ (Ctrl/⌘-ຄລິກ ໃສ່ຂໍ້ສອກເພື່ອເຮັດໃຫ້ມັນຊື່ຄືເກົ່າ), ແລະ ລາກປາຍຂອງມັນເພື່ອຊີ້ໄປຍັງຈຸດອື່ນ (Ctrl/⌘-ຄລິກ: ກັບຄືນໄປເຄິ່ງກາງຂອງອົງປະກອບ). ຄຸນສົມບັດສາມາດປ່ຽນສິ່ງທີ່ແທັກ **Shows** (ສະແດງ), ໃສ່ **Text** ສະເພາະຂອງມັນເອງ (`{mark}|{FireRating}` ຈະຂຽນເປັນສອງແຖວ), ເລືອກ **Tag type**, ຫຼື ປິດ **Leader**. ລະບົບຈະແຕ້ມແທັກຂຶ້ນມາ, ດັ່ງນັ້ນໜ້າແຜ່ນງານ ແລະ PDF ຈະພິມພວກມັນອອກມາຕາມທີ່ທ່ານເຫັນ. ປະເພດແທັກໃນ **Manage → Drafting standards → Tags** ຈະອ່ານຊ່ອງຂໍ້ມູນດຽວກັນໃນແບບແມ່ແບບຂອງພວກມັນ; ໂຄງການໃໝ່ຈະມີ Fire rating, Acoustic rating ແລະ Thermal transmittance ຢູ່ໃນນັ້ນ.

**ເສັ້ນຊີ້ແບບປ້າຍກຳກັບຂອງ ArchiCAD.** ໂດຍຄ່າເລີ່ມຕົ້ນ, ເສັ້ນຊີ້ຂອງແທັກຈະເປັນ *ຂໍ້ສອກ (elbow)*: ເສັ້ນເນິ້ງຈາກອົງປະກອບໄປຫາຫົວເຂົ່າ, ຈາກນັ້ນເປັນບ່າທີ່ແລ່ນກ້ອງຂໍ້ຄວາມ ແລະ ຂີດກ້ອງແຖວທຳອິດຂອງມັນ, ໂດຍບໍ່ມີກ່ອງອ້ອມຂໍ້ຄວາມ. ຫຼັງຈາກທີ່ທ່ານຄລິກອົງປະກອບ, ຄລິກຖັດໄປຈະເປັນຫົວເຂົ່າ ແລະ ຂໍ້ຄວາມຈະໄປຢູ່ຂ້າງມັນ. ລາກຈຸດກຣິບຂອງຫົວເຂົ່າ: ເສັ້ນເນິ້ງຈະຮັກສາມຸມ 30°, 45°, 60° ຫຼື 90° ຈາກປາຍຂອງມັນ (ກົດ <kbd>Shift</kbd> ຄ້າງໄວ້ສຳລັບທຸກໆ ມຸມ), ແລະ ເມື່ອລາກກາຍປາຍອອກໄປ ຂໍ້ຄວາມຈະຍ້າຍໄປຢູ່ເບື້ອງນັ້ນ, ຈັດລຽນໄປຫາຫົວເຂົ່າ. ລາກຂໍ້ຄວາມເພື່ອຍ້າຍມັນໄປພ້ອມກັບຫົວເຂົ່າຂອງມັນ. ໃນ **Manage → Drafting standards → Tags**, ຕົວເລືອກ **Leader…** ເທິງປະເພດແທັກ (ແລະ ຕົວແກ້ໄຂໂຄງສ້າງຊັ້ນວັດສະດຸ) ຈະກຳນົດ **Leader shape** ຂອງມັນ (ເປັນຂໍ້ສອກ, ຫຼື ຊື່ຈາກກ່ອງ), ສິ່ງທີ່ບ່າຈະຂີດກ້ອງ (**Underline**: ແຖວທຳອິດ, ແຕ່ລະແຖວ, ແຖວສຸດທ້າຍ, ຫຼື ບໍ່ມີ, ເມື່ອມັນຢຸດຢູ່ຂ້າງຂໍ້ຄວາມ) ແລະ **Extension mm**, ໄລຍະທີ່ບ່າຍື່ນອອກໄປຕື່ມຈາກຂໍ້ຄວາມ, ຢູ່ຂ້າງຕົວຢ່າງສະແດງຜົນຂອງລະບົບ. ຖ້າມີເສັ້ນຊີ້ຕໍ່ຊັ້ນວັດສະດຸ, ແຕ່ລະເສັ້ນຈະສິ້ນສຸດລົງກ້ອງແຖວຂອງຕົນເອງ, ໂດຍຫົວເຂົ່າຂອງພວກມັນຈະຢູ່ໃນຖັນດຽວກັນ; ການລາກຫົວເຂົ່າຈະຍ້າຍຖັນນັ້ນ. **Leader shape** ໃນຄຸນສົມບັດຂອງແທັກຈະຂຽນທັບປະເພດຂອງມັນ; ແທັກທີ່ມີເສັ້ນຊີ້ຖືກງໍເປັນຂໍ້ສອກແບບອິດສະຫຼະຈະຍັງຄົງຮັກສາເສັ້ນຊີ້ຊື່ຂອງມັນໄວ້. ແທັກໃນໂຄງການທີ່ສ້າງຂຶ້ນກ່ອນໜ້ານີ້ຈະຮັກສາເສັ້ນຊີ້ຊື່ໃນກ່ອງໄວ້ຄືເກົ່າ.

ເຄື່ອງໝາຍຂອງປະຕູ ຫຼື ປ່ອງຢ້ຽມ ສາມາດດັດແກ້ໄດ້ເທື່ອລະສ່ວນ, ແຕ່ລະຂໍ້ຄວາມສາມາດຍ້າຍ ຫຼື ໝຸນໄດ້ ແລະ ແຕ່ລະປາຍຂອງເສັ້ນສາມາດດຶງອອກມາໄດ້: ເບິ່ງ [ປະຕູ ແລະ ປ່ອງຢ້ຽມ](doors-windows.md).

#### ແທັກໂຄງສ້າງຊັ້ນວັດສະດຸ (Build-up tag)

ແທັກໂຄງສ້າງຊັ້ນວັດສະດຸຈະຂຽນຊັ້ນຕ່າງໆ ຂອງອົງປະກອບເປັນບັນທຶກທາງສະຖາປັດຕະຍະກຳ: ຫົວຂໍ້ (*EXTERIOR* - ພາຍນອກ), ແຖວສຳລັບແຕ່ລະຊັ້ນ, ທ້າຍຂໍ້ຄວາມ (*INTERIOR* - ພາຍໃນ). ໂຄງການໃໝ່ຈະມີ **Build-up (exterior → interior)**: ແຕ່ລະແຖວຈະເປັນຄຳອະທິບາຍຂອງວັດສະດຸ (ເປັນຊື່ຂອງມັນເມື່ອບໍ່ມີຄຳອະທິບາຍ), ຄ່າ λ ຂອງມັນເມື່ອມີ, ແລະ ຄວາມໜາຂອງຊັ້ນເປັນ ມມ. ເລືອກມັນໃນແຖບເຄື່ອງມື **Tag** ແລ້ວຄລິກໃສ່ຝາ, ພື້ນ, ຫຼັງຄາ ຫຼື ວັດສະດຸຕົກແຕ່ງຜິວຂອງຫ້ອງ; ອົງປະກອບອື່ນໆ ຈະໄດ້ຮັບຊ່ອງຂໍ້ມູນແທນ. ຂໍ້ຄວາມຈະຖືກອ່ານຈາກແບບຈຳລອງທຸກໆ ຄັ້ງທີ່ມັນຖືກແຕ້ມ: ປ່ຽນຊັ້ນ, ຄຳອະທິບາຍຂອງວັດສະດຸ ຫຼື ຄ່າ λ ຂອງມັນ, ແລ້ວແທັກກໍຈະປ່ຽນຕາມ.

![ແທັກໂຄງສ້າງຊັ້ນວັດສະດຸສອງອັນເທິງຝາດ້ານໜ້າອາຄານ: ເສັ້ນຊີ້ດຽວ, ແລະ ເສັ້ນຊີ້ໜຶ່ງອັນຕໍ່ໜຶ່ງຊັ້ນ](shots/buildup-tag.webp)

ຮູບແບບຂອງມັນຖືກຕັ້ງຄ່າໃນ **Manage → Drafting standards → Tags**: ຕັ້ງ **Shape** ຂອງປະເພດແທັກເປັນ *build-up*, ຫຼື ຄລິກ **Build-up…** ເທິງແທັກອັນໃດໜຶ່ງ, ເພື່ອດັດແກ້ມັນຢູ່ຂ້າງຕົວຢ່າງສະແດງຜົນເທິງປະເພດຝາ ຫຼື ພື້ນຂອງໂຄງການ.

- **Header text** ແລະ **Footer**: ຂຽນໄວ້ເທິງ ແລະ ກ້ອງຊັ້ນຕ່າງໆ (ຫວ່າງເປົ່າ: ບໍ່ມີ; `|` ຂຶ້ນແຖວໃໝ່).
- **Each layer**: ແຖວທີ່ຂຽນໜຶ່ງຄັ້ງຕໍ່ໜຶ່ງຊັ້ນ. ມັນອ່ານຊ່ອງຂໍ້ມູນຂອງຊັ້ນ, `{description}`, `{material}`, `{thickness}` (ໃນຫົວໜ່ວຍທີ່ເລືອກກ້ອງ **Thickness in**), `{note}` (ບັນທຶກຂອງຊັ້ນໃນປະເພດຂອງມັນ), `{function}` (ແກນຫຼັກ, ວັດສະດຸຕົກແຕ່ງຜິວ, ສະນວນ…) ແລະ `{index}`; ພາຣາມິເຕີໃດໜຶ່ງຂອງວັດສະດຸຕາມຊື່ ຫຼື ສັນຍະລັກຂອງມັນ, `{λ}`, `{μ}`, `{ρ}`, `{Reaction to fire}` (ເບິ່ງ [ຂໍ້ມູນ](materials.md#data-description-parameters-how-it-is-measured) ຂອງວັດສະດຸ); ແລະ ຂອງອົງປະກອບ, `{name}`, `{type}`, `{mark}`. **Insert a field…** ຈະໃສ່ຊ່ອງຂໍ້ມູນລົງໃນບ່ອນທີ່ເຄີເຊີຢູ່ ແລະ ສະແດງລາຍການພາຣາມິເຕີທີ່ວັດສະດຸຂອງໂຄງການມີ.
- **ວົງເລັບກ້າມ** ເຮັດໃຫ້ສ່ວນນັ້ນເປັນຕົວເລືອກເສີມ: `[, λ = {λ} W/mK]` ຈະຖືກຂຽນສະເພາະບ່ອນທີ່ວັດສະດຸມີຄ່າ λ ເທົ່ານັ້ນ; ສ່ວນນັ້ນຈະຖືກລະເວັ້ນໄປທັງໝົດເມື່ອຊ່ອງຂໍ້ມູນໃນນັ້ນຫວ່າງເປົ່າ. **[ ]** ຈະເຮັດໃຫ້ສ່ວນທີ່ເລືອກກາຍເປັນສ່ວນດັ່ງກ່າວ. ເພື່ອຂຽນຕົວວົງເລັບກ້າມເອງ, ໃຫ້ພິມ `\[` ຫຼື `\]`.
- **Order**: ຈາກພາຍນອກຫາພາຍໃນຂອງຝາ (ດ້ານຊັ້ນທຳອິດຂອງມັນແມ່ນດ້ານນອກ, ດັ່ງນັ້ນຝາທີ່ກັບດ້ານກໍຍັງເລີ່ມຈາກບ່ອນນັ້ນ), ຈາກເທິງຫາລຸ່ມຂອງພື້ນ ຫຼື ຫຼັງຄາ; ຫຼື ໃນທາງກັບກັນ. ເລືອກລຳດັບທີ່ແລ່ນໄປຕາມລັກສະນະທີ່ຊັ້ນຕ່າງໆ ວາງຢູ່ຂ້າງບັນທຶກ, ເພື່ອບໍ່ໃຫ້ເສັ້ນຊີ້ຕໍ່ຊັ້ນຕັດກັນ.
- **ຊັ້ນທີ່ບໍ່ມີຄວາມໜາ** (ແຜ່ນກັນຊຶມ, ແຜ່ນຟອຍ, ສີ) ຈະຖືກຂຽນ ນອກຈາກວ່າທ່ານຈະປົດຕິກ **shown** ອອກ. ຊັ້ນທີ່ມີການປ່ຽນວັດສະດຸຕາມຄວາມສູງຈະຂຽນແຍກແຖວສຳລັບແຕ່ລະວັດສະດຸ.
- **Leaders**: ເສັ້ນດຽວ, ໄປຫາອົງປະກອບ, ຫຼື **one per layer** (ໜຶ່ງເສັ້ນຕໍ່ຊັ້ນ), ແຕ່ລະເສັ້ນຈາກແຖວຂອງມັນໄປຫາຈຸດພາຍໃນຊັ້ນຂອງມັນເອງ, ບ່ອນທີ່ມຸມມອງສາມາດແຍກແຕ່ລະຊັ້ນອອກຈາກກັນໄດ້ (ຝາໃນແປນ ແລະ ໜ້າຕັດ, ພື້ນໃນໜ້າຕັດ; ສ່ວນບ່ອນອື່ນໆ ແທັກຈະຮັກສາໄວ້ເສັ້ນດຽວ). ລາກປາຍເສັ້ນຊີ້ໄປຕາມອົງປະກອບເພື່ອຕັດຜ່ານມັນຢູ່ບ່ອນອື່ນ.
- **Lines start with** ເລີ່ມຕົ້ນດ້ວຍຈຸດຫົວແຖວ, ເຄື່ອງໝາຍຂີດ, ໝາຍເລກຂອງພວກມັນ ຫຼື ບໍ່ໃສ່ຫຍັງເລີຍ; ພວກມັນຈະຕັດຂຶ້ນແຖວໃໝ່ຕາມ **Width mm** ເທິງໜ້າເຈ້ຍ, ໂດຍຫຍໍ້ໜ້າຫ້ອຍຫຼັງຈຸດຫົວແຖວ, ແລະ ຄ່າຕ່າງໆ ຈະຢູ່ຄູ່ກັບສັນຍະລັກ ແລະ ຫົວໜ່ວຍຂອງມັນສະເໝີ (`λ = 0.035 W/mK`).

![ຕົວດັດແກ້ປະເພດແທັກໂຄງສ້າງຊັ້ນວັດສະດຸຢູ່ຂ້າງຕົວຢ່າງສະແດງຜົນ](shots/buildup-tag-type.webp)

ຄືກັນກັບແທັກອື່ນໆ, ແທັກໂຄງສ້າງຊັ້ນວັດສະດຸຈະໄປຕາມອົງປະກອບຂອງມັນ, ແລະ ໜ້າແຜ່ນງານ ແລະ PDF ຈະພິມອອກມາຕາມທີ່ທ່ານເຫັນ, ຮວມທັງ λ, μ ແລະ ρ. ສ່ວນ **Text** ສະເພາະຂອງມັນເອງໃນຄຸນສົມບັດ ຈະປ່ຽນແທນແຖວຕໍ່ຊັ້ນສຳລັບແທັກນັ້ນພຽງອັນດຽວ.

### ແກນຕາໜ່າງ

**Annotate → Grid axis** (<kbd>GR</kbd>) ຈະແຕ້ມແກນໜຶ່ງແກນຕາມສອງສົ້ນຂອງມັນ; ມັນຈະໃຊ້ປ້າຍຊື່ຖັດໄປຕາມທິດທາງຂອງມັນ. **Annotate → Axis grid…** ຈະວາງຕາໜ່າງທັງໝົດພ້ອມກັນໃນບາດດຽວ: ໄລຍະຫ່າງ **Across** (ແກນທີ່ເປັນຕົວເລກ, ຈາກຊ້າຍຫາຂວາ) ແລະ **Along** (ແກນທີ່ເປັນຕົວອັກສອນ, ຈາກລຸ່ມຂຶ້ນເທິງ) ໃນຫົວໜ່ວຍຂອງໂຄງການ, ເຊັ່ນ `6000 6000 4500` ຫຼື `3*6000`; **Origin** ບ່ອນທີ່ແກນທຳອິດຕັດກັນ, **Angle** (ມຸມ), ໄລຍະທີ່ແກນແລ່ນ **Past the grid** (ເລີຍຕາໜ່າງອອກໄປ), **First labels** (ປ້າຍຊື່ທຳອິດ) ແລະ **Axis type** (ປະເພດແກນ). ເມື່ອໝາຍຕິກ **replace the grid's axes** ໄວ້, ແກນທີ່ແຕ້ມມາກ່ອນໜ້ານີ້ຈະຖືກລຶບອອກ.

![ກ່ອງໂຕ້ຕອບ Axis grid](shots/grid-dialog.webp)

ຄລິກໃສ່ແກນໃດໜຶ່ງເພື່ອເລືອກມັນ. ຄຸນສົມບັດຂອງມັນຈະສະແດງ **Start** (ຈຸດເລີ່ມຕົ້ນ) ແລະ **End** (ຈຸດສິ້ນສຸດ), **Length** (ຄວາມຍາວ), **Angle** (ມຸມ), ແລະ ໄລຍະຫ່າງຂອງມັນຈາກແກນຂະໜານທີ່ຢູ່ກ່ອນໜ້າມັນ (↔). ພິມໄລຍະຫ່າງໃໝ່ແລ້ວແກນຈະຍ້າຍ; ແກນທີ່ຢູ່ຖັດຈາກມັນກໍຈະຍ້າຍໄປຄືກັນ, ເວັ້ນເສຍແຕ່ທ່ານຈະປົດຕິກ **the axes beyond move too** ອອກ. **Bubbles** ເລືອກວ່າສົ້ນໃດຈະມີວົງມົນໃສ່ຊື່ແກນ. **Axis styles…** ຈະເປີດ **Drafting standards → Grid axes**, ບ່ອນທີ່ວົງມົນ, ຂະໜາດຂອງມັນ, ປະເພດເສັ້ນ ແລະ ປ້າຍຊື່ທຳອິດຖືກກຳນົດໄວ້. ເລືອກຕາໜ່າງທັງໝົດເພື່ອສະແດງລາຍການແກນ ແລະ ໄລຍະຫ່າງຂອງພວກມັນ.

![ຄຸນສົມບັດຂອງແກນຕາໜ່າງ](shots/axis-properties.webp)

ທຸກໆ ຄວາມຍາວຢູ່ນີ້ແມ່ນເປັນໄປຕາມຫົວໜ່ວຍຂອງໂຄງການ. ໃນຫົວໜ່ວຍຟຸດ ແລະ ນິ້ວ, ຈຸດປາຍ ແລະ ໄລຍະຫ່າງຈະອ່ານເປັນ 19'-8 1/4", ແລະ ລະດັບຕ່າງໆ ກໍຈະຖືກຂຽນເປັນຟຸດ ແລະ ນິ້ວເຊັ່ນກັນ.
