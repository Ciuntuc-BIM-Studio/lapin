## ລະດັບຊັ້ນ

ແຖບທ່ອງໂຄງການຈະສະແດງລາຍຊື່ລະດັບຊັ້ນຕ່າງໆ ໄວ້ທາງເທິງ, ໂດຍເລີ່ມຈາກລະດັບຊັ້ນສູງສຸດກ່ອນ. ເຄື່ອງໝາຍ **+** ທີ່ຢູ່ຂ້າງ **Levels** ຈະເພີ່ມລະດັບຊັ້ນໃສ່ທາງເທິງຂອງຊັ້ນທີ່ສູງສຸດ.

ເລືອກລະດັບຊັ້ນເພື່ອເບິ່ງ **base level** (ລະດັບພື້ນຖານ) ແລະ **top level** (ລະດັບເທິງ). ທັງສອງສາມາດຢູ່ເໜືອ ຫຼື ຢູ່ກ້ອງ ±0.00 ໄດ້. ຄວາມສູງຂອງມັນແມ່ນໄລຍະຫ່າງລະຫວ່າງສອງລະດັບດັ່ງກ່າວ. ເມື່ອທ່ານຍ້າຍລະດັບພື້ນຖານ, ລະດັບເທິງຈະຍັງຄົງຢູ່ບ່ອນເກົ່າ. ໂຄງການໃໝ່ຈະເລີ່ມຕົ້ນດ້ວຍ Foundations (ຮາກຖານ), Ground floor (ຊັ້ນພື້ນດິນ) ແລະ First floor (ຊັ້ນໜຶ່ງ). ລະດັບຊັ້ນໜຶ່ງສາມາດສູງໄດ້ຫຼາຍສຸດ 100 ແມັດ ແລະ ຢູ່ພາຍໃນຂອບເຂດ ±10 ກິໂລແມັດ ຈາກ ±0.00: ຄ່າທີ່ພິມຜິດຫົວໜ່ວຍຈະຖືກປະຕິເສດ. ຂັ້ນໄດທີ່ຈະຂຶ້ນສູງເກີນ 50 ແມັດ ໄປຫາລະດັບຊັ້ນເທິງຈະຢຸດຢູ່ພຽງເທົ່ານັ້ນ ແລະ ແຈ້ງເຫດຜົນ.

![ຄຸນສົມບັດຂອງລະດັບຊັ້ນ: base level, top level ແລະ ຄວາມສູງ](shots/level-properties.webp)

ແຕ່ລະລະດັບຊັ້ນຈະມີແປນຂອງຕົນເອງຢູ່ກ້ອງ **Floor plans**. ກົດສອງບາດໃສ່ແປນເພື່ອແຕ້ມລົງໃນລະດັບຊັ້ນນັ້ນ. ລະດັບຊັ້ນທີ່ທ່ານກຳລັງແຕ້ມຈະສະແດງຢູ່ໃນກ່ອງຢູ່ມຸມເທິງເບື້ອງຊ້າຍຂອງມຸມມອງ.

ໃນຮູບໜ້າຕັດ ແລະ ຮູບດ້ານ ແຕ່ລະລະດັບຊັ້ນຈະຖືກໝາຍໄວ້ທາງເບື້ອງຂວາພ້ອມດ້ວຍຊື່ ແລະ ລະດັບຄວາມສູງຂອງມັນ. ຄຳສັ່ງ **Manage → Object styles → Hidden lines** ຍັງໃຊ້ຕັ້ງຄ່າ **level marker** (ເຄື່ອງໝາຍລະດັບຊັ້ນ) ໄດ້ອີກດ້ວຍ: ຮູບສາມແຈໂປ່ງ, ຮູບສາມແຈທີ່ເຄິ່ງຊ້າຍເປັນສີດຳ (ຕາມມາດຕະຖານຂອງປະເທດໂຣມານີ), ຮູບສາມແຈສີດຳ ຫຼື ເຄື່ອງໝາຍຖືກ, ລວມທັງຂະໜາດຂອງມັນເທິງໜ້າເຈ້ຍ.

ລະດັບຄວາມສູງແມ່ນຂຽນຕາມຫົວໜ່ວຍຂອງໂຄງການ: ເປັນແມັດ (+3.00) ໃນໂຄງການລະບົບເມຕຣິກ, ຄືດັ່ງທີ່ແບບແຕ້ມຂຽນລະດັບຊັ້ນ, ແລະ ເປັນຟຸດກັບນິ້ວ (+9'-10 1/8") ໃນໂຄງການລະບົບອິມພີຣຽວ. ແຖບທ່ອງ, ກ່ອງຢູ່ມຸມເທິງເບື້ອງຊ້າຍຂອງມຸມມອງ, ເຄື່ອງໝາຍລະດັບຊັ້ນໃນຮູບໜ້າຕັດ ແລະ ຮູບດ້ານ, ຕະຫຼອດຮອດເສັ້ນບອກໄລຍະຂອງລະດັບຊັ້ນ ທັງໝົດລ້ວນແຕ່ປ່ຽນຕາມກັນ.

## ການເບິ່ງເຫັນລະດັບຊັ້ນກ້ອງ

ເພື່ອເບິ່ງເຫັນອີກລະດັບຊັ້ນໜຶ່ງໃນຂະນະທີ່ທ່ານແຕ້ມ, ໃຫ້ເລືອກຊັ້ນນັ້ນໃນ **Underlay** ຢູ່ແຖບຂອງແປນ. ແປນຂອງລະດັບຊັ້ນດັ່ງກ່າວຈະຖືກແຕ້ມຢູ່ກ້ອງ, ເປັນສີເທົາຈາງໆ. ທ່ານສາມາດສະແນັບ (snap) ໃສ່ມັນໄດ້, ແຕ່ບໍ່ສາມາດເລືອກ (select) ມັນໄດ້.

![ຊັ້ນໜຶ່ງທີ່ຖືກແຕ້ມທັບເທິງຊັ້ນພື້ນດິນ, ສະແດງເປັນ underlay](shots/underlay.webp)

Underlay ມີໄວ້ເພື່ອຊ່ວຍທ່ານແຕ້ມເທົ່ານັ້ນ; ມັນຈະບໍ່ຖືກພິມອອກມາ. ເພື່ອພິມອົງປະກອບຂອງລະດັບຊັ້ນອື່ນໆ ລົງໃນແປນ, ໃຫ້ເປີດຄຸນສົມບັດຂອງມຸມມອງແປນ ແລ້ວເລືອກພວກມັນໃນ **Storeys shown**. ທ່ານສາມາດເລືອກສະແດງບາງລະດັບຊັ້ນ ຫຼື ທັງໝົດກໍໄດ້, ໂດຍສະແດງເປັນສີເຄິ່ງໂທນ (halftone) ຖ້າທ່ານຕ້ອງການ.

## ການສຳເນົາໄປຫາລະດັບຊັ້ນອື່ນ

ເພື່ອເຮັດຊ້ຳຝາ, ພື້ນ ຫຼື ຜັງທັງໝົດໄປໃສ່ລະດັບຊັ້ນອື່ນ, ໃຫ້ເລືອກເອົາສິ່ງນັ້ນ (ຝາພ້ອມທັງປະຕູ ແລະ ປ່ອງຢ້ຽມຂອງມັນ, ພື້ນ, ຫ້ອງ, ກຸ່ມ…) ແລ້ວເລືອກ **Modify → Copy to storeys**. ທ່ານຍັງສາມາດພິມ `COPYSTOREY` ໃສ່ແຖວຄຳສັ່ງ (command line), ຫຼື ຄລິກຂວາໃສ່ສິ່ງທີ່ເລືອກໃນແປນ ຫຼື ໃນມຸມມອງ 3D. ໝາຍຕິກໃສ່ລະດັບຊັ້ນທີ່ຕ້ອງການສຳເນົາໄປຫາ. **All above** ແລະ **All below** ຈະໝາຍຕິກທຸກລະດັບຊັ້ນທີ່ຢູ່ເທິງ ຫຼື ຢູ່ກ້ອງຊັ້ນຂອງສິ່ງທີ່ເລືອກ, ແລະ ການກົດ Shift ຄ້າງໄວ້ແລ້ວຄລິກ ຈະໝາຍຕິກທຸກລະດັບຊັ້ນທີ່ຢູ່ລະຫວ່າງກາງຂອງຊັ້ນນັ້ນກັບຊັ້ນສຸດທ້າຍທີ່ທ່ານຄລິກ. ລະດັບຊັ້ນທີ່ສິ່ງທີ່ເລືອກຕັ້ງຢູ່ຈະບໍ່ສາມາດໝາຍຕິກໄດ້.

![Copy to storeys: ໝາຍຕິກສອງລະດັບຊັ້ນ, ແລະ ຕົວເລືອກຕ່າງໆ](shots/copy-to-storeys.webp)

- **Relative** (ຄ່າເລີ່ມຕົ້ນ): ແຕ່ລະອັນທີ່ສຳເນົາຈະຕັ້ງຢູ່ລະດັບຄວາມສູງດຽວກັນເໜືອລະດັບຊັ້ນໃໝ່ ຄືກັນກັບຕົ້ນສະບັບເໜືອລະດັບຊັ້ນເກົ່າ. ຝາທີ່ແຕ້ມຢູ່ຊັ້ນພື້ນດິນຈະຕັ້ງຢູ່ເທິງຊັ້ນໜຶ່ງ.
- **Absolute**: ແຕ່ລະອັນທີ່ສຳເນົາຈະຍັງຄົງຢູ່ບ່ອນເກົ່າໃນຊ່ອງຫວ່າງ (space), ແຕ່ຂຶ້ນກັບລະດັບຊັ້ນໃໝ່. ຄ່າໄລຍະຫ່າງພື້ນຖານ (base offset) ຈະຊົດເຊີຍສ່ວນຕ່າງນັ້ນ.
- **Hosted elements too**: ປະຕູ ແລະ ປ່ອງຢ້ຽມຈະໄປພ້ອມກັບຝາຂອງພວກມັນ, ແລະ ຊ່ອງເຈາະຈະໄປພ້ອມກັບສິ່ງທີ່ມັນເຈາະ. ປ້າຍຊື່ (tags) ແລະ ເສັ້ນບອກໄລຍະຂອງອົງປະກອບທີ່ຖືກສຳເນົາຈະຍ້າຍຈາກແປນລະດັບຊັ້ນເດີມໄປຫາແປນລະດັບຊັ້ນໃໝ່. ຫ້ອງຈະເອົາຜິວຕົກແຕ່ງໄປນຳ ແລະ ຂັ້ນໄດຈະເອົາຊ່ອງຫວ່າງກ້ອງຂັ້ນໄດໄປນຳ. ປົດໝາຍຕິກອອກຫາກຕ້ອງການສຳເນົາຝາໂດຍບໍ່ເອົາປະຕູ ແລະ ປ່ອງຢ້ຽມ.
- **Rebuild relations among the copies**: ຝາທີ່ເຊື່ອມຕໍ່ກັນຢູ່ມຸມ ຫຼື ຮູບໂຕ T ຈະເຊື່ອມຕໍ່ກັນໃນແບບດຽວກັນເທິງແຕ່ລະລະດັບຊັ້ນໃໝ່. ຝາທີ່ຕິດກັບພື້ນ ຫຼື ຫຼັງຄາທີ່ຖືກສຳເນົາໄປພ້ອມກັນ ກໍຈະຕິດກັບອົງປະກອບທີ່ສຳເນົານັ້ນ. ກຸ່ມຈະກາຍເປັນກຸ່ມຂອງອົງປະກອບທີ່ສຳເນົາ, ແລະ ຊິ້ນສ່ວນປະກອບ (assembly) ຈະຖືກສຳເນົາໄປທັງໝົດ. ຂັ້ນໄດຈະຂຶ້ນສູ່ລະດັບຊັ້ນທີ່ຢູ່ເທິງຊັ້ນໃໝ່ຂອງມັນ ແລະ ເຈາະຊ່ອງເປີດຂອງຕົນເອງຢູ່ເທິງພື້ນຊັ້ນນັ້ນ.
- **Skip duplicates**: ລະດັບຊັ້ນທີ່ມີອົງປະກອບອັນດຽວກັນຢູ່ບ່ອນດຽວກັນແລ້ວ ຈະບໍ່ໄດ້ຮັບອັນທີສອງຕື່ມ. ຂໍ້ຄວາມຢູ່ທາງລຸ່ມຈະບອກວ່າໄດ້ຂ້າມໄປຈັກອັນ.

ອົງປະກອບທີ່ສຳເນົາຈະໃຊ້ປະເພດດຽວກັນກັບຕົ້ນສະບັບ ແລະ ໄດ້ຮັບ IFC GlobalId ໃໝ່. ການສຳເນົາທັງໝົດສາມາດຍົກເລີກການກະທຳ (undo) ໄດ້ໃນຂັ້ນຕອນດຽວ, ແລະ ພວກມັນຈະຍັງຖືກເລືອກໄວ້ຫຼັງຈາກນັ້ນ, ເພື່ອໃຫ້ທ່ານສາມາດຍ້າຍ ຫຼື ປ່ຽນແປງພວກມັນພ້ອມກັນໄດ້. ໃນເຊດຊັນທີ່ໃຊ້ຮ່ວມກັນ, ສິ່ງທີ່ແຂກ (guest) ສຳເນົາຈະສາມາດຍົກເລີກການກະທຳໄດ້ໂດຍແຂກຜູ້ນັ້ນເທົ່ານັ້ນ.
