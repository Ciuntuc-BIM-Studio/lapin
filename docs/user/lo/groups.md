## ກຸ່ມ

ກຸ່ມຊ່ວຍຮວບຮວມບັນດາອົງປະກອບເຂົ້າໄວ້ນຳກັນ. ເລືອກພວກມັນແລ້ວກົດ **Modify → Create group** (<kbd>GP</kbd>). ຈາກນັ້ນ ການກົດໃສ່ສະມາຊິກໃດໜຶ່ງຈະເປັນການເລືອກທັງໝົດກຸ່ມ, ທັງໃນໜ້າແຜນຜັງ ແລະ ໃນແບບ 3D. ກຸ່ມຈະຍ້າຍ, ສຳເນົາ, ໝຸນ, ພິກດ້ານ ແລະ ລຶບ ພ້ອມກັນເປັນອັນດຽວ, ແລະ ສຳເນົາທີ່ໄດ້ກໍຈະເປັນກຸ່ມສະເພາະຂອງມັນເອງ. ໃນ IFC, ກຸ່ມຈະເປັນ IfcGroup, ດັ່ງນັ້ນ ໂປຣແກຣມອື່ນໆ ຈຶ່ງສາມາດມອງເຫັນມັນໄດ້ເຊັ່ນກັນ.

ຄຸນສົມບັດຂອງກຸ່ມທີ່ຖືກເລືອກ ຈະສະແດງຈຳນວນອົງປະກອບທີ່ບັນຈຸຢູ່ພາຍໃນ, ພ້ອມດ້ວຍສາມປຸ່ມ: **Edit group**, **Ungroup** ແລະ **Select members**.

![ເລືອກກຸ່ມແລ້ວ: ສະມາຊິກຂອງມັນຮຸ່ງແຈ້ງຂຶ້ນ, ຄຸນສົມບັດຂອງມັນ](shots/group-selected.webp)

## ການແກ້ໄຂກຸ່ມ

ກົດສອງບາດໃສ່ສະມາຊິກ, ຫຼື ກົດ **Edit group** (<kbd>EG</kbd>). ສ່ວນທີ່ເຫຼືອຂອງໂມເດວຈະສະແດງເປັນສີຈາງລົງ ແລະ ບໍ່ສາມາດເລືອກໄດ້, ແລະ ການກົດຈະເລືອກສະມາຊິກໄດ້ເທື່ອລະອັນ. ລຶບ, ຍ້າຍ ຫຼື ປ່ຽນແປງສະມາຊິກໄດ້ຕາມປົກກະຕິ. **Remove from group** ຈະນຳເອົາສະມາຊິກທີ່ເລືອກອອກໄປ. **Done**, ຫຼື <kbd>Esc</kbd>, ຈະປິດກຸ່ມ. ກຸ່ມຈະໝົດໄປເມື່ອສະມາຊິກໂຕສຸດທ້າຍຖືກລຶບອອກ.

![ເປີດກຸ່ມເພື່ອແກ້ໄຂ: ກຳແພງສວນທີ່ຢູ່ນອກກຸ່ມເປັນສີຈາງລົງ](shots/group-edit.webp)

## ໄຟລ໌ທີ່ນຳເຂົ້າ

ທຸກໆ ໄຟລ໌ IFC, Fragments ຫຼື mesh ທີ່ທ່ານນຳເຂົ້າ ຈະເຂົ້າມາເປັນກຸ່ມດຽວທີ່ຕັ້ງຊື່ຕາມໄຟລ໌ນັ້ນ. ຕິກເອົາ **As one group** ອອກໃນຕອນນຳເຂົ້າ IFC ເພື່ອນຳເອົາບັນດາອົງປະກອບເຂົ້າມາແບບແຍກກັນ. ໄຟລ໌ທີ່ເຊື່ອມໂຍງຈະບໍ່ຖືກຈັດເປັນກຸ່ມ: ມັນເປັນການເຊື່ອມໂຍງອັນດຽວຢູ່ແລ້ວ, ແບບອ່ານໄດ້ຢ່າງດຽວ (ເບິ່ງ [ການນຳເຂົ້າ ແລະ ການສົ່ງອອກ](import-export.md)). ອົງປະກອບທີ່ອ່ານມາຈາກໄຟລ໌ IFC ໃນຖານະຈຸດອ້າງອີງ ຈະຢູ່ບ່ອນທີ່ໄຟລ໌ວາງໄວ້: ກຸ່ມຂອງພວກມັນສາມາດຈັດເກັບສະສາງ ແລະ ລຶບອອກໄດ້, ແຕ່ຍ້າຍບໍ່ໄດ້.

## ການເລືອກຕາມຂອບເຂດໃນແບບ 3D

**View → Select region** (<kbd>SR</kbd>) ຈະປ່ຽນການລາກເມົ້າຊ້າຍໃນມຸມມອງ 3D ໃຫ້ເປັນການເລືອກ, ຄືກັນກັບໃນໜ້າແຜນຜັງ. ເມື່ອລາກໄປທາງຂວາ, ກອບປ່ອງຢ້ຽມຈະເລືອກເອົາສິ່ງທີ່ຢູ່ພາຍໃນມັນທັງໝົດ. ເມື່ອລາກໄປທາງຊ້າຍ, ຂອບຕັດຈະເລືອກເອົາສິ່ງທີ່ມັນແຕະຖືກ. ກົດ <kbd>Space</kbd> ໃນຂະນະທີ່ລາກເພື່ອແຕ້ມເປັນເຊືອກບ້ວງ, ແລະ ກົດ <kbd>Shift</kbd> ເພື່ອເພີ່ມເຂົ້າໃນການເລືອກ. ໃນຂະນະທີ່ເປີດໃຊ້ຢູ່, ປຸ່ມຂວາຈະໝຸນມຸມມອງ ແລະ ປຸ່ມກາງຈະຍ້າຍມຸມມອງ. ເຄື່ອງໝາຍ **×** ຢູ່ເທິງປ້າຍຂອງມັນ, ຫຼື ກົດ <kbd>SR</kbd> ອີກເທື່ອໜຶ່ງ, ຈະເປັນການປິດມັນ.

![ການລາກຂອບຕັດຜ່ານເຮືອນໃນແບບ 3D](shots/select-region-3d.webp)

## ການເຊື່ອງຊົ່ວຄາວ

**View → Hide** (<kbd>HH</kbd>) ຈະເຊື່ອງສິ່ງທີ່ຖືກເລືອກໃນມຸມມອງ 3D. **Isolate** (<kbd>HI</kbd>) ຈະເຊື່ອງສິ່ງອື່ນໆ ທັງໝົດ. **Show all** (<kbd>HR</kbd>), ຫຼື ເຄື່ອງໝາຍ **×** ຢູ່ເທິງປ້າຍ, ຈະເອົາທຸກຢ່າງກັບຄືນມາ. ບໍ່ມີສິ່ງໃດຖືກບັນທຶກ ຫຼື ລຶບຖິ້ມ: ມັນເປັນພຽງວິທີການເຂົ້າເຖິງສິ່ງທີ່ຢູ່ທາງໃນຂອງໂມເດວທີ່ນຳເຂົ້າມາ ໃນຂະນະທີ່ທ່ານກຳລັງຈັດເກັບສະສາງມັນ.
