# ຄູ່ມືຜູ້ໃຊ້ Lapin

Lapin ແມ່ນເຄື່ອງມືສ້າງແບບຈຳລອງ BIM ສຳລັບສະຖາປະນິກ ແລະ ວິສະວະກອນ. ທ່ານແຕ້ມຝາ, ພື້ນ, ຫຼັງຄາ, ປະຕູ ແລະ ປ່ອງຢ້ຽມໃນແຜນຜັງ. Lapin ຈະສ້າງແບບຈຳລອງ 3D ຂຶ້ນມາຈາກສິ່ງເຫຼົ່ານັ້ນ, ແລະ ແຕ້ມຮູບຕັດ, ຮູບດ້ານ ລວມທັງແຜ່ນງານທີ່ທ່ານພິມ. ແຕ່ລະອົງປະກອບແມ່ນອົງປະກອບ IFC ແທ້, ດັ່ງນັ້ນແບບຈຳລອງຈຶ່ງສາມາດສົ່ງຕໍ່ໄປຫາເຄື່ອງມື BIM ອື່ນໆໄດ້ຕາມສະພາບເດີມ.

Lapin ເຮັດວຽກໄດ້ໃນສອງບ່ອນ:

- **ຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ.** ແອັບເດັສທັອບສຳລັບ Windows, macOS ແລະ Linux ແມ່ນໄວທີ່ສຸດ. ມັນອັບເດດຕົວເອງໄດ້.
- **ຢູ່ໃນບຣາວເຊີ.** [lapin.ciuntucbimstudio.ro](https://lapin.ciuntucbimstudio.ro/web/) ໃຊ້ງານແອັບດຽວກັນໄດ້ໂດຍບໍ່ຕ້ອງຕິດຕັ້ງຫຍັງເລີຍ. ມັນຈະຊ້າກວ່າໜ້ອຍໜຶ່ງ.

![ພື້ນທີ່ເຮັດວຽກຂອງ Lapin ພ້ອມເຮືອນຫຼັງນ້ອຍໃນແຜນຜັງຊັ້ນພື້ນດິນ](shots/workspace.webp)

> ຮູບພາບໃນຄູ່ມືນີ້ແມ່ນຖ່າຍມາຈາກຕົວ Lapin ເອງທຸກຄັ້ງທີ່ມີການເຜີຍແຜ່ເວີຊັນໃໝ່, ດັ່ງນັ້ນຈຶ່ງສະແດງໃຫ້ເຫັນຕົວແອັບຄືກັນກັບສະພາບຕົວຈິງໃນປະຈຸບັນ.

## ເລີ່ມຕົ້ນຈາກໃສ

ຫາກໍ່ເລີ່ມໃຊ້ Lapin ບໍ? ອ່ານ [ການເລີ່ມຕົ້ນໃຊ້ງານ](getting-started.md), ຈາກນັ້ນອ່ານ [ຝາ](walls.md). ສ່ວນໜ້າອື່ນໆແມ່ນສາມາດອ່ານຕາມລຳດັບໃດກໍໄດ້. ມັກເບິ່ງຫຼາຍກວ່າບໍ? [ວິດີໂອ](videos.md) ມີບົດສອນສັ້ນໆສຳລັບແຕ່ລະພາກສ່ວນຂອງ Lapin.

## ຟຣີ, ໂອເພນຊອດ ແລະ helpware

Lapin ແມ່ນໃຊ້ໄດ້ຟຣີ ແລະ ເປັນໂອເພນຊອດ, ພາຍໃຕ້ໃບອະນຸຍາດ MIT; ໂຄ້ດຂອງມັນຢູ່ເທິງ [GitHub](https://github.com/Ciuntuc-BIM-Studio/lapin). ມັນຍັງເປັນ **helpware**: ຖ້າ Lapin ຊ່ວຍທ່ານໄດ້ບໍ່ວ່າທາງໃດກໍ່ຕາມ, ພວກເຮົາຂໍຊຸກຍູ້ທ່ານ, ໂດຍບໍ່ໄດ້ບັງຄັບ, ໃຫ້ຊ່ວຍເຫຼືອໃຜກໍ່ຕາມທີ່ຕ້ອງການຄວາມຊ່ວຍເຫຼືອ ໃນທຸກວິທີທີ່ທ່ານສາມາດເຮັດໄດ້: ບໍ່ວ່າຈະເປັນເວລາຂອງທ່ານ, ຄວາມຮູ້ຄວາມສາມາດຂອງທ່ານ, ການຍື່ນມືຊ່ວຍເຫຼືອຄົນໃກ້ຄຽງ, ຂອງຂວັນໃຫ້ແກ່ຜູ້ຄົນ ຫຼື ເປົ້າໝາຍທີ່ທ່ານເຊື່ອໝັ້ນ. Lapin ບໍ່ໄດ້ຮຽກຮ້ອງສິ່ງໃດເພື່ອຕົນເອງ ແລະ ບໍ່ຮັບການບໍລິຈາກໃດໆ.

## ເມື່ອທ່ານຕິດຂັດ

ກົດ **Ask Me** ເຊິ່ງເປັນຮູບກະຕ່າຍຢູ່ມຸມຂວາເທິງຂອງແອັບ, ຫຼື ກົດ <kbd>F1</kbd>, ແລ້ວພິມຄຳຖາມຂອງທ່ານດ້ວຍຄຳເວົ້າຂອງທ່ານເອງ. ຖ້າມັນບໍ່ມີຄຳຕອບ, ມັນຈະສົ່ງຄຳຖາມຂອງທ່ານມາຫາພວກເຮົາ. ເບິ່ງ [ຄວາມຊ່ວຍເຫຼືອ ແລະ ຄຳຕິຊົມ](help.md).
