## ການບັນທຶກ ແລະ ການເປີດ

**File → Save** (<kbd>Ctrl</kbd> <kbd>S</kbd>) ຈະບັນທຶກເປັນໄຟລ໌ `.lapin`, ແລະ **File → Open…** (<kbd>Ctrl</kbd> <kbd>O</kbd>) ຈະເປີດໄຟລ໌ຂຶ້ນມາ.

- **ແອັບເດັສທັອບ.** ໄຟລ໌ຈະຖືກບັນທຶກໄວ້ໃນບ່ອນທີ່ທ່ານເລືອກ.
- **ບຣາວເຊີ, Chrome ແລະ Edge.** Lapin ຈະບັນທຶກທັບລົງໃນໄຟລ໌ເກົ່າທຸກໆຄັ້ງ.
- **ບຣາວເຊີ, Safari ແລະ Firefox.** ການບັນທຶກແຕ່ລະຄັ້ງຈະເປັນການດາວໂຫຼດໄຟລ໌.

ໄຟລ໌ `.lapin` ເກັບຮັກສາທຸກຢ່າງຂອງໂຄງການ: ໂມເດວ, ມຸມມອງຕ່າງໆ, ແຜ່ນແບບ, ວັດສະດຸພ້ອມດ້ວຍຮູບພາບຂອງພວກມັນ, ແລະ ເວີຊັນຕ່າງໆ.

## ການກູ້ຄືນວຽກທີ່ຍັງບໍ່ໄດ້ບັນທຶກ

Lapin ຈະເກັບຮັກສາວຽກທີ່ຍັງບໍ່ໄດ້ບັນທຶກຂອງທ່ານໄວ້ເລື້ອຍໆໃນຂະນະທີ່ທ່ານເຮັດວຽກ. ຖ້າແອັບ ຫຼື ຄອມພິວເຕີຢຸດເຮັດວຽກກ່ອນທີ່ທ່ານຈະບັນທຶກ, ໜ້າຈໍເລີ່ມຕົ້ນຈະແຈ້ງເຕືອນໃຫ້ກູ້ຄືນວຽກນັ້ນໃນຄັ້ງຕໍ່ໄປ.

## ເວີຊັນ

ເວີຊັນ ແມ່ນສະພາບຂອງໂຄງການຕາມທີ່ມັນເປັນຢູ່ໃນຕອນທີ່ທ່ານບັນທຶກ: ເຊັ່ນ ກ່ອນການປະຊຸມກັບລູກຄ້າ, ຫຼື ເມື່ອສິ້ນສຸດຂັ້ນຕອນການອອກແບບ. ເປີດ **File → Save version…** ຫຼື **Manage → Versions**.

![ເວີຊັນ: ບັນທຶກໂຄງການຕາມສະພາບປັດຈຸບັນ](shots/versions.webp)

ເວີຊັນຕ່າງໆຈະຖືກເກັບໄວ້ພາຍໃນໄຟລ໌ຂອງໂຄງການ, ແລະ ສ່ວນທີ່ເວີຊັນໃຊ້ຮ່ວມກັນກັບໂຄງການຈະຖືກເກັບໄວ້ພຽງຄັ້ງດຽວເທົ່ານັ້ນ. ຈາກລາຍການ ທ່ານສາມາດ:

- ປ່ຽນຊື່ເວີຊັນ;
- ອັບເດດໃຫ້ເປັນສະພາບປັດຈຸບັນ, ພ້ອມກັບການດັດແກ້;
- ປຽບທຽບມັນກັບໂຄງການ, ເທື່ອລະອົງປະກອບ;
- ກູ້ຄືນມັນ, ເຊິ່ງເປັນບາດກ້າວໜຶ່ງທີ່ທ່ານສາມາດຍົກເລີກການເຮັດ (undo) ຄືນໄດ້;
- ສົ່ງອອກ ຫຼື ເປີດມັນແຍກຕ່າງຫາກ;
- ລຶບມັນຖິ້ມ.

## Undo

<kbd>Ctrl</kbd> <kbd>Z</kbd> ໃຊ້ຍົກເລີກການກະທຳ (undo), ແລະ <kbd>Ctrl</kbd> <kbd>Y</kbd> ຫຼື <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> ໃຊ້ເຮັດຄືນໃໝ່ (redo). ປຸ່ມ **Undo** ແລະ **Redo** ຢູ່ເທິງແຖບດ້ານເທິງ, ທາງເບື້ອງຂວາຂອງ **Commands…**, ຈະເຮັດວຽກແບບດຽວກັນໃນທຸກໂໝດໜ້າຕ່າງການນຳໃຊ້, ແລະ ຂໍ້ຄວາມແນະນຳ (tooltip) ຈະບອກວ່າປຸ່ມນັ້ນຍົກເລີກຫຍັງ; **File → Undo** ແລະ **File → Redo**, ລວມທັງແຖບລວມຄຳສັ່ງ (<kbd>Ctrl</kbd> <kbd>K</kbd>, ພິມ "undo") ກໍເຊັ່ນດຽວກັນ.
