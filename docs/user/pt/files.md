## Salvar e abrir

**Arquivo → Salvar** (<kbd>Ctrl</kbd> <kbd>S</kbd>) grava um arquivo `.lapin`, e **Arquivo → Abrir…** (<kbd>Ctrl</kbd> <kbd>O</kbd>) abre um.

- **Aplicativo para desktop.** O arquivo é salvo onde você escolher.
- **Navegador, Chrome e Edge.** O Lapin salva sempre no mesmo arquivo.
- **Navegador, Safari e Firefox.** Cada salvamento baixa o arquivo.

Um arquivo `.lapin` guarda o projeto inteiro: o modelo, as vistas, as pranchas, os materiais com suas próprias imagens e as versões.

## Recuperar o trabalho não salvo

O Lapin guarda o seu trabalho não salvo enquanto você trabalha. Se o aplicativo ou o computador parar antes de você salvar, a tela inicial oferece a recuperação na próxima vez.

## Versões

Uma versão é o projeto como ele está no momento em que você o salva como versão: antes de uma reunião com o cliente ou no fim de uma etapa do projeto. Abra **Arquivo → Salvar versão…** ou **Gerenciar → Versões**.

![Versões: salve o projeto como ele está agora](shots/versions.webp)

As versões ficam dentro do arquivo do projeto, e as partes que uma versão tem em comum com o projeto são guardadas uma única vez. Na lista você pode:

- renomear uma versão;
- atualizá-la para o estado atual, com uma revisão;
- compará-la com o projeto, elemento por elemento;
- restaurá-la, como um único passo que pode ser desfeito;
- exportá-la ou abri-la separadamente;
- excluí-la.

## Desfazer

<kbd>Ctrl</kbd> <kbd>Z</kbd> desfaz, e <kbd>Ctrl</kbd> <kbd>Y</kbd> ou <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> refaz. Os botões **Desfazer** e **Refazer** na barra superior, à direita de **Comandos…**, fazem o mesmo em todos os modos da interface, e a dica deles diz o que desfazem; **Arquivo → Desfazer** e **Arquivo → Refazer**, e a paleta de comandos (<kbd>Ctrl</kbd> <kbd>K</kbd>, digite "desfazer"), também.
