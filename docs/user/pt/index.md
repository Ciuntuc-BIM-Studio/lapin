# Guia do usuário do Lapin

O Lapin é um modelador BIM para arquitetos e engenheiros. Você desenha paredes, lajes, telhados, portas e janelas em planta. O Lapin constrói o modelo 3D a partir deles e desenha os cortes, as elevações e as pranchas que você imprime. Cada elemento é um elemento IFC de verdade, então o modelo vai para outras ferramentas BIM do jeito que está.

O Lapin roda em dois lugares:

- **No seu computador.** O aplicativo para desktop, para Windows, macOS e Linux, é o mais rápido. Ele se atualiza sozinho.
- **No navegador.** [lapin.ciuntucbimstudio.ro](https://lapin.ciuntucbimstudio.ro/web/) roda o mesmo aplicativo sem instalar nada. É um pouco mais lento.

## Gratuito, de código aberto e helpware

O Lapin é gratuito e de código aberto, sob a licença MIT; o código está no [GitHub](https://github.com/Ciuntuc-BIM-Studio/lapin). Ele também é **helpware**: se o Lapin ajuda você de alguma forma, nós incentivamos você, sem obrigar, a ajudar quem precisa, como puder: com seu tempo, suas habilidades, uma mão para alguém por perto, uma doação para pessoas ou uma causa em que você confia. O Lapin não pede nada para si e não aceita doações.

## Quando você travar

Clique em **Pergunte-me**, o coelho no canto superior direito do aplicativo, ou pressione <kbd>F1</kbd> e digite sua pergunta com suas próprias palavras. Se não houver resposta, ele envia sua pergunta para nós. Veja [Ajuda e feedback](help.md).
